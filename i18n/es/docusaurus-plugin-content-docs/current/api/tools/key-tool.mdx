# Herramienta de gestión de claves {#key-tool}

La herramienta de gestión de claves es una aplicación de escritorio de ZAI. Reúne tus claves de API en un solo lugar y configura el acceso a la API de ZAI para Claude y Codex, así que no tienes que editar a mano los archivos de configuración. Las claves se siguen creando en la sección **API keys** de la [consola para desarrolladores](https://ourzai.com/console).

Tras instalar, inicia sesión para importar claves o añade una manualmente, y elige el cliente y el modelo que quieras iniciar. Instala Claude o Codex por separado.
