# 密鑰管理工具 {#key-tool}

密鑰管理工具是 ZAI 提供的桌面應用程式，用來集中管理你的 API 密鑰，並為 Claude 與 Codex 配置 ZAI API 接入，毋須手動編輯配置檔案。密鑰仍然在[開發者控制台](https://ourzai.com/console)「API 密鑰」裡新建。

## 下載 {#download}

| 系統 | 安裝程式 |
| --- | --- |
| Windows | 即將提供 |
| macOS | 即將提供 |

安裝程式發佈後會在本頁提供下載連結。在此之前，請按下面的教程手動配置。

## 手動配置 {#manual}

不使用密鑰管理工具時，按各工具的教程配置：

- [Claude Code](./claude-code.md)
- [Claude 桌面版](./claude-desktop.md)
- [Codex CLI](./codex-cli.md)
- [Codex 桌面版](./codex-app.md)
