# 密鑰管理工具 {#key-tool}

密鑰管理工具是 ZAI 提供的桌面應用程式，用來集中管理你的 API 密鑰，並為 Claude 與 Codex 配置 ZAI API 接入，毋須手動編輯配置檔案。密鑰仍然在[開發者控制台](https://ourzai.com/console)「API 密鑰」裡新建。

## 下載 {#download}

<KeyToolDownload keysLabel="密鑰" previewLabel="應用程式預覽">

[Windows 版 · v0.2.6](https://ourzai.com/downloads/key-manager/0.2.6/zAI-Key-Manager_Windows_x64-setup.exe)

Windows · x64

[macOS 版 · v0.2.6](https://ourzai.com/downloads/key-manager/0.2.6/zAI-Key-Manager_macOS.dmg)

macOS 12+ · Intel / Apple Silicon

[GitHub 原始碼](https://github.com/z55183980-gif/ourzai-keytool)

</KeyToolDownload>

安裝後，登入匯入或手動新增密鑰，選擇客戶端與模型即可啟動。Claude 與 Codex 需另外安裝。
