# 賬戶、餘額與支援 {#account}

## 註冊賬戶 {#register}

各產品都有註冊入口，從任何一處註冊得到的都是同一個 ZAI 賬戶，註冊一次即可登入全部產品：

| 從哪裡註冊 | 入口 | 註冊後 |
| --- | --- | --- |
| 官網 | 右上角「註冊」，或登入視窗裡的「還沒有賬戶？註冊」 | 登入成功後留在當前頁面 |
| 開發者控制台 | 登入頁底部的「去註冊」 | 自動登入並進入控制台 |
| 遇見 Zai | [zai.gg](https://zai.gg) 登入頁的註冊入口 | 按頁面提示進入陪伴產品 |
| ZaiDrama | 登入彈窗切換到「建立你的 ZAI 賬戶」，可填寫邀請碼 | 直接進入 ZaiDrama |

使用電郵註冊時：

- 需要填寫電郵收到的 6 位驗證碼（10 分鐘內有效，60 秒後可重新發送）；
- 密碼至少 6 位，需同時包含字母和數字；
- 同一個電郵只能註冊一次，已註冊會提示「這個電郵已經註冊過了」，直接去登入即可。

如果註冊前在官網首頁和 Zai 聊過，這段對話會跟著進入新賬戶。

## 登入賬戶 {#sign-in}

- 用註冊時的電郵和密碼登入。
- 官網、遇見 Zai 與 ZaiDrama 使用統一賬戶登入；已有有效登入狀態時可直接進入，狀態過期或需要驗證時按頁面提示重新登入。
- 登入頁提供 Google 登入時，也可以選擇「使用 Google 賬戶繼續」；首次使用會按頁面流程建立賬戶。
- 已在官網登入時，點首頁的「創作工作台」會免密進入 ZaiDrama。
- 登入狀態會自動續期；同一個賬戶同時登入的裝置過多時，最早的會話會被擠下線。

## 忘記密碼 {#reset-password}

在登入視窗點「忘記密碼？」，輸入註冊電郵，收到驗證碼後設定新密碼。為了不暴露某個電郵是否註冊過，輸入未註冊的電郵時頁面同樣會提示已發送。

## 賬戶安全 {#account-security}

在 ZaiDrama 的「個人中心」可以：

- 更換綁定電郵（更換後用新電郵登入各產品）；
- 修改密碼；
- 查看「登入裝置」，把不認識的裝置逐個退出；
- 註銷賬戶：輸入完整電郵和密碼，閱讀清除範圍並再次確認。提交後會退出登入；資料清理可能需要時間，以頁面顯示的處理結果為準。註銷不可撤銷。

不要把密碼、驗證碼或 API 密鑰發給任何人，包括自稱客服的人。

## 餘額 {#credits}

- **一份餘額**：餘額以美元計。開發者控制台右上角顯示的餘額和 ZaiDrama 裡的餘額是同一個賬戶。ZaiDrama 生成圖片、影片、配音，以及通過 API 調用模型，都從這裡扣費；與官網平台助手對話不扣平台餘額。
- **增值**：在開發者控制台的「增值」頁或 ZaiDrama 的「賬單與餘額」頁購買增值包。每個增值包標明到賬金額（美元，含贈送部分）；以人民幣標價的增值包按人民幣付款，到賬同樣是美元餘額。付款由 Stripe 處理，支援銀行卡、支付寶和微信支付，平台不儲存銀行卡資訊；支付寶和微信到賬可能稍有延遲，付款確認後自動入賬。
- **不過期**：增值到賬的餘額不會過期。
- **單價**：各模型的美元單價（每百萬 Token 或每個計費單位）在控制台「模型定價」查看。ZaiDrama 的每次生成按「費率 × 用量」扣費，精確到 $0.0001，最低 $0.0001；開拍確認卡和審批條會先給出報價。
- **顯示**：餘額類數字（右上角餘額、餘額卡片、累計增值 / 消費）顯示 2 位小數並向下截斷，例如 `$1,234.56`，懸停可看 4 位精確值；每筆扣費、流水、報價等明細顯示 4 位小數，例如 `$0.0123`。
- **記錄**：控制台「增值」頁的「賬單」標籤和 ZaiDrama「賬單與餘額」頁可以查看增值記錄；API 消耗在控制台「使用記錄」查看，ZaiDrama 的扣費明細在「賬單與餘額」查看。

### 獎勵 {#rewards}

ZaiDrama 的「福利中心」提供：

- **每日登入獎勵**：活動開放且滿足領取條件時，在 ZaiDrama 登入可自動領取；頁面提供領取按鈕時，也可按提示操作。金額、次數和累計上限以當前活動規則為準；
- **推薦獎勵**：通過邀請連結或邀請碼邀請新用戶，按活動規則獲得餘額獎勵。

獎勵金額進入同一個餘額。具體數額以福利中心頁面為準。

## 遇見 Zai 的會員 {#companion-plans}

遇見 Zai 使用同一個平台賬戶，但免費版、Zai Plus、語音回覆與通話時長、加量包在陪伴產品的會員頁面管理。平台餘額增值不等於購買會員，也不會把餘額數字變成語音分鐘數。

查看當前權益、恢復日期、購買與到期規則，見[會員與用量](../zai/plans-and-usage.md)。聊天、形象與記憶的操作從[遇見 Zai 快速開始](../zai/getting-started.md)進入。

## 退款 {#refunds}

退款規則見[服務條款](https://ourzai.com/legal/terms.html)第 6 節「訂閱、付款與退款」，價格、退款等具體規則以購買頁面展示為準。需要申請退款時，寫信到 support@ourzai.com，寫明註冊電郵和訂單資訊。

## 聯絡與支援 {#support}

| 渠道 | 適合 | 誰能用 |
| --- | --- | --- |
| 官網首頁的 Zai | 了解平台、找說明文件、查可用模型和公開單價 | 所有人，無需註冊 |
| 開發者控制台「新對話」 | 登入後直接問 Zai 接口怎麼調、模型怎麼選 | 已登入用戶 |
| ZaiDrama「幫助與反馈」 | 創作過程中的問題，人工線上客服，可以發截圖 | 已登入的 ZaiDrama 用戶 |
| [官網聯絡我們](https://ourzai.com/contact) | 聯絡線上客服、查看其他聯絡渠道 | 所有人 |
| support@ourzai.com | 賬戶問題、退款申請、商務合作 | 所有人 |

官網首頁的 Zai 暫時連不上時，會出現「轉人工客服」按鈕，之前的對話會一起轉給客服。
