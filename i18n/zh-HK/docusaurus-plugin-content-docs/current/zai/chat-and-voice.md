# 聊天與語音 {#chat-and-voice}

在 [遇見 Zai](https://zai.gg) 中，可以打字聊天、發送語音，也可以直接與 Zai 通話。

## 文字聊天 {#text-chat}

在聊天輸入框輸入內容並發送。Zai 回覆時可以繼續閱讀聊天記錄；如果現時回覆不再需要，可使用界面上的停止按鈕結束當前任務。

連線中斷時，先查看頁面提示，再重試發送。若問題持續，記錄發生時間和錯誤提示，透過[聯絡與支援](../platform/account.md#support)反映。

## 三種語音用法 {#voice-options}

| 功能 | 你會怎樣使用 | 與其他功能的區別 |
| --- | --- | --- |
| 語音訊息 | 使用輸入區的麥克風錄音，按提示發送 | 用說話代替打字發送一條訊息 |
| 語音回覆 | 在聊天中切換到語音模式，聆聽 Zai 的回覆 | Zai 把回覆說給你聽，使用語音回覆時長 |
| 語音通話 | 點擊「語音通話」，允許使用麥克風後實時交談 | 獨立的通話過程，使用語音通話時長 |

語音回覆和語音通話分別顯示額度。錄製一條語音訊息不等於開啟實時通話。

## 調整語音回覆 {#voice-replies}

1. 在聊天界面切換到語音模式。
2. 在語音模式選項中設定是否自動播放。
3. 到「設定 → 聲音」選擇音色、調整音量，並查看本期剩餘語音回覆時長。

需要安靜閱讀時，切回文字模式即可。語音回覆時長耗盡時，界面會提示改用文字回覆；恢復時間和可用加量包見[會員與用量](./plans-and-usage.md)。

## 進行語音通話 {#voice-call}

1. 點擊聊天界面的「語音通話」。
2. 瀏覽器詢問麥克風權限時選擇允許，並確認裝置的麥克風可用。
3. 通話中可以靜音或取消靜音、開關 Zai 的聲音。桌面版收起通話視窗後，點擊最小化通話列恢復；不要用人物下方的通話按鈕恢復，它在通話中會掛斷。
4. 結束交流時點擊「結束」或「掛斷」。流動版請直接使用通話畫面的控制按鈕，不套用桌面視窗的收起操作。

如果頁面提示通話額度已用完，在會員中查看恢復時間與加量包。如果提示暫時無法通話，稍後重試。

## 沒有聲音或無法錄音 {#troubleshooting}

- **無法錄音**：檢查瀏覽器的網站麥克風權限，以及系統中是否選取了正確的輸入裝置。
- **聽不到回覆**：檢查裝置和頁面音量、分頁是否靜音，以及語音回覆是否開啟。瀏覽器阻止自動播放時，手動點擊播放。
- **通話聽不到 Zai**：檢查通話界面的聲音開關；麥克風靜音控制的是你說話的聲音。
- **有額度但仍失敗**：記錄頁面錯誤提示，重新整理後重試；持續失敗時聯絡支援。

音色的選擇與更換見[形象、聲音與相處關係](./appearance-and-relationship.md#voice)。
