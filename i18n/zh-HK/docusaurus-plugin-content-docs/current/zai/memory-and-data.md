# 記憶與數據管理 {#memory-and-data}

Zai 會在對話後整理長期記憶，幫助延續之後的交流。記憶不等於逐字保存所有聊天，也不保證每句話立即成為一條可見記憶。

## 查看和管理記憶 {#manage-memory}

1. 打開「設置 → 私隱與數據」。
2. 點擊「查看和管理記憶」，進入記憶庫。
3. 查看已保存的內容；發現不準確的記憶時，可以修正對應條目，不想保留的條目可以刪除。
4. 操作後檢查頁面結果；如果提示失敗，重新加載後確認當前內容再重試。

聊天記錄與長期記憶分別管理。需要查看或刪除聊天消息時，在聊天窗口操作。

## 暫停新增記憶 {#pause-memory}

在「設置 → 私隱與數據」打開「暫停記憶」。開啟後，新聊的內容不會整理進長期記憶，已經記住的內容仍會照常使用。

關閉該開關後，可以繼續整理新的記憶。暫停記憶不會清除已有記憶，也不是刪除聊天記錄的操作。

## 導出數據與導入記憶 {#export-and-import}

- **導出數據**：在「私隱與數據 → 數據管理」中點擊「導出數據」旁的「下載」，保存包含聊天、記憶、日記等內容的導出文件。
- **導入記憶**：在同一頁面選擇「導入記憶」，按頁面提示選擇導出文件。導入會添加記憶並保留現有記憶，**不會恢復聊天和日記**。

導出文件包含你的個人對話資料，請保存在自己可控制的位置。導入、導出的成功或失敗以頁面結果為準。

匯出檔案中的語音記錄只保留文字，不包含音訊。聊天中交付並儲存在用戶端的文件正文不在伺服器匯出範圍內；如需保留，請另行儲存。匯出檔案並非整個應用程式狀態的完整備份。

## 重新開始 {#start-over}

「私隱與數據」中的「重新開始」會清除聊天、記憶、便簽和日記。賬戶、會員、形象、音色和關係設置保留。

清除後無法恢復。需要保留資料時，先導出數據；確認清除範圍後再點擊「確認清除」。導入記憶不能把整個聊天歷史恢復回來。

賬戶註銷與重新開始是不同操作。賬戶安全、條款和支持渠道見[賬戶、餘額與支持](../platform/account.md)。
