# 會員與用量 {#plans-and-usage}

遇見 Zai 提供免費版、Zai Plus 會員和加量包。登入後前往 [Zai Plus](https://zai.gg/subscription) 比較及購買方案；如要查看自己的剩餘額度和恢復日期，請開啟產品選單中的「會員」。

## 查看計劃與價格 {#plans}

頁面顯示免費版與 Zai Plus 的權益，以及不同相伴時長的價格。購買前核對所選時長、實際支付金額和所含額度；具體價格、額度與可用方案以該頁面為準。

會員採用一次性付款，到期不會自動續費。已有會員時，再購買的時長會接在現有有效期之後。支付完成後返回產品，確認會員狀態和有效期已更新。

## 查看剩餘用量 {#allowances}

在產品選單開啟「會員」，查看本期語音回覆、語音通話的剩餘額度和恢復日期；「設定 → 聲音」亦可查看語音回覆時長。獨立的 `/subscription` 頁面用於比較及購買方案，不顯示本期用量。語音回覆和通話分開計量，不能互相挪用。

定製形象的生成次數與語音分鐘數分開計算；音色名額是可儲存自訂音色的容量，不是每次使用聲音都扣一次。具體數量以頁面顯示為準。

## 額度用完與加量包 {#extra-packs}

語音回覆額度用完時，可以繼續使用文字回覆；語音通話額度用完時，頁面會提示等待恢復或查看可用的加量包。

加量包只限有效 Zai Plus 會員購買，採用一次性付款。

購買方案附送的形象生成次數在會員有效期內可以累加；到期時未用完的附送次數清零，已完成的形象保留。另購加量包可包括語音回覆分鐘、通話分鐘、形象生成次數和音色名額：先用會員自帶額度，再用相應加量包。加量包不按月重設；會員到期後餘額凍結並保留，重新開通後恢復，已儲存的自訂音色不會因此刪除。

## 與平台餘額的區別 {#platform-balance}

API 調用與 ZaiDrama 媒體生成使用平台美元餘額。遇見 Zai 的會員有效期、語音時長和加量包屬於陪伴產品權益，應在會員中查看和購買。

給 API 或 ZaiDrama 增值，不等於購買 Zai Plus；平台餘額也不代表剩餘語音分鐘數。平台增值記錄與相關規則見[賬號、餘額與支持](../platform/account.md#credits)。

## 付款後權益沒有更新 {#payment-help}

先確認登入的是購買時使用的賬號，再刷新會員頁面查看有效期與額度。付款仍在處理中時，等待付款結果；已成功付款但權益持續未更新時，聯繫 support@ourzai.com，提供註冊電郵、訂單信息和發生時間。

申請退款及相關條款入口見[退款](../platform/account.md#refunds)。
