# 遇見 Zai 常見問題 {#faq}

## 從哪裡進入？需要 API 密鑰嗎？ {#entry}

開啟 [zai.gg](https://zai.gg) 即可。使用現有 ZAI 賬戶登入，不需要自行建立或填寫 API 密鑰。初次使用請參閱[快速開始](./getting-started.md)。

## 有平台賬戶，為甚麼還要登入？ {#sign-in}

同一個賬戶可以用於多個產品，但跨產品的登入狀態可能不同。使用原電郵登入即可，不必重複註冊。忘記密碼時使用登入頁的找回入口；詳情請參閱[賬戶說明](../platform/account.md#reset-password)。

## 為甚麼聽不到聲音，或者無法使用麥克風？ {#audio}

檢查裝置音量、瀏覽器音訊和麥克風權限、聊天的語音模式，以及通話中的靜音與聲音開關。語音回覆和語音通話分別設有額度；排查步驟請參閱[聊天與語音](./chat-and-voice.md#troubleshooting)。

## 平台有餘額，為甚麼還提示語音額度用完？ {#allowance}

平台美元餘額與遇見 Zai 的語音權益分別管理。請到會員查看對應的語音回覆或通話剩餘時長、恢復日期與加量包；詳情請參閱[會員與用量](./plans-and-usage.md)。

## Zai 記錯了，或者沒記住，怎麼辦？ {#memory}

記憶會在對話後整理，不是每句話都會立即成為長期記憶。請先檢查「暫停記憶」是否開啟；在記憶庫查看已儲存內容，並修正或刪除不準確的條目。具體操作請參閱[記憶與資料管理](./memory-and-data.md)。

## 換形象或名字會清空記憶嗎？ {#appearance}

不會。更換形象和名字會保留記憶。清理過往內容需要使用記憶管理或「重新開始」；後者會清除聊天、記憶、便簽和日記，操作前請閱讀[清除範圍](./memory-and-data.md#start-over)。

## 匯入記憶可以恢復全部聊天嗎？ {#import}

不能。匯入會新增記憶並保留原有記憶，不恢復聊天和日記。匯出資料與匯入記憶的範圍請參閱[資料管理](./memory-and-data.md#export-and-import)。

## 遇到問題找誰？ {#support}

在遇見 Zai 的產品選單選擇「在線客服」，即可直接求助。

請聯絡 support@ourzai.com，說明發生在哪個產品、註冊電郵、發生時間和頁面錯誤提示；付款問題請附上訂單資料。切勿發送密碼、驗證碼或 API 密鑰。更多渠道請參閱[聯絡與支援](../platform/account.md#support)。
