# 形象、聲音與相處關係 {#appearance-and-relationship}

在遇見 Zai 的設置中，可以分別調整外觀、聲音和相處方式。

## 更換形象 {#appearance}

開啟「設置 → 形象」，選擇喜歡的形象。頁面也提供自訂形象入口；涉及生成時，先查看頁面顯示的權益和剩餘次數。

換形象會帶來推薦音色；如果你已經手動選過音色，原先的選擇會保留。更換形象不會改變名字、性格和記憶。

## 選擇聲音 {#voice}

開啟「設置 → 聲音」，選擇音色並調整音量。這裡也顯示本期語音回覆的剩餘時長。

創建自己的音色是否可用，取決於當前語音模型的支援情況。頁面提示暫不支援時，已有音色會保留；當前模型無法使用已選的自訂音色時，會暫用形象預設聲音，恢復支援後再使用你的選擇。

語音回覆與實時通話的操作見[聊天與語音](./chat-and-voice.md)。

## 修改名字 {#name}

在「設置 → 相處關係」找到「TA 的名字」，點擊修改並儲存。名字只影響稱呼，不會重設性格或記憶。

## 選擇相處關係 {#relationship}

在「設置 → 相處關係」中選擇：

| 關係 | 相處方式 |
| --- | --- |
| 朋友 | 平等、隨意，可以開玩笑，也會直接表達看法 |
| 戀人 | 更親暱地表達關心與想念 |
| 前輩 | 更注重督促、建議和直接指出問題 |

選擇戀人關係時，頁面會要求確認已年滿 18 歲，確認後才儲存。關係選擇會影響互動方式，Zai 的身份仍然是 AI。

儲存失敗時按提示重試，並檢查頁面當前選中的關係。若想清理過往聊天或記憶，使用[記憶與數據管理](./memory-and-data.md)中的對應操作。
