# 遇見 Zai：快速開始 {#getting-started}

遇見 Zai 是 ZAI 的 AI 陪伴產品。你可以和 Zai 聊日常、分享心事，選擇喜歡的形象與相處關係，也可以用語音回覆和通話交流。

**[打開遇見 Zai](https://zai.gg)**

## 開始第一次聊天 {#first-chat}

1. 開啟 [zai.gg](https://zai.gg)，選擇喜歡的形象、確認名字，再選擇朋友、戀人或前輩關係；選擇戀人須確認已滿 18 歲。
2. 點擊「開始」，按提示登入或註冊。已有賬戶請使用原賬戶；登入後以賬戶儲存的形象、名字和關係為準。
3. 新賬戶會先進入初遇序章。你可以完成互動或略過，然後開始自由聊天。
4. 在輸入框寫下想說的話並傳送，例如：「今天有點累，陪我聊一會兒。」
5. 想聽 Zai 的聲音時，切換到語音回覆；想實時交談時，使用「語音通話」。兩者的操作與用量見[聊天與語音](./chat-and-voice.md)。

完成初遇並選過回應後，符合回訪條件時，在之後一天回來可能會聽到 Zai 提起那句話；這不是定時推送通知。形象、名字、聲音和關係之後都可以在設定中調整。

## 賬戶與使用權益 {#account-and-access}

遇見 Zai 使用 ZAI 平台賬戶。跨產品打開時可能需要重新登入，但不需要為每個產品建立一個賬戶。註冊、密碼找回和支援渠道見[賬戶、餘額與支援](../platform/account.md)。

遇見 Zai 的免費版、Zai Plus 和語音等權益在產品的會員頁面查看。API 與 ZaiDrama 使用的平台美元餘額，不能等同於遇見 Zai 的會員權益或語音額度；詳見[會員與用量](./plans-and-usage.md)。

## 幾個入口裡的 Zai {#which-zai}

- **zai.gg 的 Zai**：這裡介紹的 AI 夥伴，提供日常陪伴、相處設定和記憶管理。
- **官網首頁與開發者控制台的 Zai**：平台助手，幫助了解產品、查說明文件和 API 使用方式。
- **ZaiDrama 裡的 Zai**：創作助手，和你一起推進創作項目或畫布任務。

這些入口服務於不同用途。本文的操作步驟以 zai.gg 為準。
