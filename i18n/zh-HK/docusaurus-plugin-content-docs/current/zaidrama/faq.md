# ZaiDrama 常見問題 {#faq}

本文彙總 ZaiDrama 創作應用程式中最常見的賬戶、製作、生產與下載問題。第一次使用時，建議先閱讀[ZaiDrama 入門教學](./getting-started.md)；平台賬戶與餘額請參閱[賬戶、餘額與支援](../platform/account.md)。

## 使用 ZaiDrama 前需要了解哪些能力邊界？ {#capability-boundaries}

- 媒體生成由平台統一調度上游模型服務，生成速度、可用性和內容政策會隨目前能力狀態變化。
- Zai 會自動推進大部分步驟，但長篇內容仍建議你審閱方案、角色定妝圖和關鍵片段；ZaiDrama 的目標是增強創作者，而不是取消判斷。
- 不同影片模型對參考圖數量、時長、音軌和解析度的支援不同。
- 開啟網站並登入即可開始，無需安裝軟件或設定第三方 API 密鑰。

## 註冊、登入與賬戶 {#install-deploy-update}

### 一般用戶怎樣開始？ {#how-to-install}

在落地頁點「開始創作」，註冊或登入統一平台賬戶後進入首頁，在輸入框裡說出你想做的影片，或附上小說、劇本和參考圖。發送第一句話就會建立項目並進入項目頁，這一步不產生費用。

### 怎樣登入？忘記密碼怎麼辦？ {#default-login}

- 登入彈窗支援電郵或用戶名登入；沒有預設賬戶，需要先註冊。
- 忘記密碼時在登入彈窗點「忘記密碼？」，用電郵驗證碼重設。
- 已登入時想更換密碼，在賬戶選單的「個人中心」點「修改密碼」。
- 從 ourzai.com 點「創作工作台」進入，已有有效登入狀態時無需再次輸入密碼；ZaiDrama 與 ZAI 平台共用同一個賬戶。

不要要求任何人透過聊天發送你的密碼或驗證碼。

### 怎樣查看登入裝置或註銷賬戶？ {#account-security}

在「個人中心」的「登入裝置」裡可以看到所有已登入裝置，並對單個裝置點「退出」；「註銷賬戶」也在個人中心。

### 平台頁面打不開或請求失敗怎麼辦？ {#page-request-failure}

先確認網絡連接和登入狀態，重新整理頁面重試。只有單個項目或生成失敗時，先看對話或批次頁裡寫明的失敗原因。持續失敗時，在賬戶選單的「幫助與反饋」聯絡線上客服，說明發生時間和所在頁面；需要時可以在「設定 → 診斷日誌」下載診斷日誌發給客服。不要上傳環境檔案或在聊天中貼上密鑰。

### 平台怎樣更新？會遺失項目嗎？ {#platform-updates}

網站會自動更新，用戶無需安裝更新套件。更新期間已提交給模型服務的影片會接着等待結果，少數進行中的圖片任務可能被標記為中斷，需要重新生成那一項。已完成的產物不會被新版本靜默覆蓋。

### 項目存在哪裡？怎樣備份？ {#where-is-data}

項目、素材和生成結果保存在平台上。建議下載需要長期保留的內容。你可以隨時下載成片、可編輯套件和旁白音訊留存，但平台不提供項目級 ZIP 匯出，賬戶和餘額等資料也不包含在任何下載內容中。

### 儲存空間滿了怎麼辦？ {#storage-full}

在賬戶選單的「儲存空間」查看容量上限和各項目的佔用，用「清理歷史」刪除不再需要的歷史版本（只刪歷史版本，目前使用的版本保留）。

## 與 Zai 對話 {#setup-and-assistant}

### 開始製作前需要設定哪些憑證？ {#required-credentials}

不需要。一般用戶只需統一平台賬戶；Zai 的對話、文字／圖像／影片／語音能力和任務資源都由平台提供。

### 怎樣讓 Zai 開始或繼續製作？ {#start-or-resume-assistant}

在項目的 Zai 對話裡直接說明目標，例如「開始製作」「接着拍剩下的」。Zai 會先看項目目前進度，從沒完成的地方繼續。它需要你決定時會在輸入框上方彈出提問卡或確認卡。

### Zai 會不會不問我就花錢？ {#assistant-spending}

不會超出你批准的範圍：

- 開拍前 Zai 會給出報價，你點「批准並開拍」後，這筆額度內的步驟自動執行，不再逐步打斷；
- 超出開拍額度、返工額度不足時，會再次彈卡確認；
- 分析源文、整理方案、首次寫劇本這類不產生費用的動作會直接做完再告訴你；
- 要覆蓋你親手改過的內容時，也會先徵得你同意。

### 可以先只拍一部分嗎？ {#partial-production}

可以。對 Zai 說「先拍第一集」或「只拍前兩段」，報價和額度只算這些片段，之後的分鏡和影片都守這個範圍。拍完後再告訴 Zai 接着拍剩下的。

### 我在工作台上直接改了東西，Zai 知道嗎？ {#workbench-edits}

知道。你在資產庫新增條目，Zai 會先讀再問你要怎麼用；切換版本、重新合成等操作會在對話裡留一行記錄，Zai 下次開口前會看到。Zai 要覆蓋你改過的內容時會先請你確認，卡上逐條列出「舊 → 新」。

### Zai 無法啟動或請求逾時怎麼辦？ {#assistant-startup-failure}

先重新整理頁面；Zai 的連接斷開後會自動重連，正在進行的這一輪不會因此中斷。仍然無法使用時，記下發生時間，透過「幫助與反饋」聯絡線上客服。

## 模型與供應商 {#providers-models-api}

### ZaiDrama 支援哪些模型？我能自己選嗎？ {#supported-providers}

平台按用途（文生圖、圖生影片、參考生影片、旁白等）為每次調用挑選模型，可用範圍以產品頁面為準。你可以在「項目資訊」的劇集參數（專業模式）、項目設定的旁白配音和創意畫布的生成面板裡，從平台開放的候選中選擇；Zai 的對話模型不能選。詳見[模型與能力](./models.md)。

### 能在 ZaiDrama 裡使用自己的模型供應商嗎？ {#custom-provider-setup}

不能。ZaiDrama 提供可直接使用的模型，不支援新增自己的模型供應商。

- 想在自己的程式裡調用平台上的模型：到開發者控制台建立 API 密鑰，base_url 填 `https://api.ourzai.com/v1`，請參閱 [API 快速開始](../api/quickstart.md)。
- ZaiDrama「設定 → API 權杖」建立的是供外部工具存取 ZaiDrama 本身的權杖，和開發者控制台的 API 密鑰不是一回事。

### 生成失敗了怎麼辦？ {#auth-rate-limit-timeout}

先看失敗原因：對話裡的提交卡片和批次頁都會寫明哪幾個沒成、為甚麼。上游限流或暫時不可用時平台會自動重試；重試無效時只重拍受影響的片段，不要重複提交整批。提交後發生逾時，上游任務可能已經建立，不要連續盲目重試，稍等後查看結果，仍有問題再聯絡客服。

## 項目流程與生產 {#project-workflow-and-tasks}

### 需要先選說書、劇集或廣告模式嗎？ {#choose-mode-and-route}

不需要。項目沒有內容模式，也沒有建立後鎖定的生成路線。Zai 根據素材為每個片段決定類型（表演、旁白、展示等）和影片生成方式（分鏡引導或參考引導），同一集裡可以混用。詳見[創作流程](./workflows.md)。

### 來源檔案支援哪些格式？ {#supported-source-formats}

- 檔案：`.txt`、`.md`、`.docx`、`.epub`、`.pdf`，單一檔案不超過 50MB，一次最多附 5 個；
- 圖片：PNG、JPG、WebP，單張不超過 5MB，一次最多 5 張；
- 首頁和項目裡的 Zai 輸入框都可以直接附檔案和圖片；項目的「文稿」頁也可以「上傳來源檔案」；
- 一次貼上很長的文字會自動收成一張「貼上的文字」卡片，發送後存成源文。

掃描版 PDF 沒有可提取的文字，需要先做 OCR；舊式 `.doc` 請先轉成 `.docx`。

### 生產進度在哪裡看？ {#production-progress}

- 頂欄中間的狀態標籤，例如「生產中 · 分鏡 8/11」「需要你決定」；
- 工作台「看板」的五站進度、「需要你決定」和「最新產出」；
- 「批次」頁逐批預覽，每段可以查看發給影片模型的提示詞和失敗原因。

### 為甚麼生產停住了？ {#stage-blocked}

常見原因：

- 有一步在等你確認（看板會顯示「有一步在等你確認」，確認卡在對話框上方）；
- 角色有多套造型，但某些片段還沒選造型；
- 某一站有片段沒做成，需要你決定重試還是修改；
- 這次開拍的範圍已經做完，要接着拍剩下的需要告訴 Zai。

### 怎樣暫停、繼續或取消生產？ {#task-states}

直接在對話裡告訴 Zai，例如「先暫停」「繼續」「取消這次生產」。取消後再繼續只會補做被取消或缺失的部分，已完成的結果會保留重用。

### 只想重拍某一段怎麼辦？ {#reshoot-segment}

在對話裡說清哪一段、怎麼改，例如「第 3 段她再冷一點」。Zai 會給出舊 → 新的改法對照，確認後只重做這一段影片。重拍使用開拍額度之外的返工額度，額度不夠時會再請你確認。

### 怎樣避免滿意的版本被重新生成取代？ {#pin-version}

在該素材的「歷史版本」裡點「鎖定目前版本」。鎖定後重新生成的結果只進入歷史候選，不會自動取代目前版本；也可以隨時「切換到此版本」換回以前的結果。

## 畫面、影片與聲音 {#visuals-video-audio}

### 怎樣提高角色一致性？ {#character-consistency}

先確認角色定妝圖（一張圖包含頭肩特寫和正面、側面、背面全身），再生成分鏡和影片。全域資產庫支援搜尋和跨項目重用。資產定義變化後，已有的分鏡和影片不會被靜默覆蓋，而是標記為比目前內容舊，由你決定是否重拍。

### 角色在劇中換裝怎麼辦？ {#character-looks}

為角色新增**造型**：在資產庫的角色詳情裡點「新增造型」，填寫髮型、服裝、配飾並生成定妝圖（需要先有主造型定妝圖）。然後在劇本裡為每一段選擇這個角色穿哪一套；沒選的段會停在劇本步驟。也可以直接讓 Zai 替你寫造型、給片段補選造型。

### 怎樣讓相鄰片段更連貫？ {#shot-continuity}

鎖定角色、場景和造型後再生成影片，保持地點、時間、服裝和出場角色描述一致。分鏡引導的片段會參考前一段的分鏡畫面來銜接。

### 首幀和尾幀怎樣使用？ {#first-and-last-frame}

項目裡分鏡引導的片段以分鏡圖作為影片首幀，不使用尾幀。需要同時控制首幀和尾幀時，可以在[創意畫布](./canvas.md)的影片節點上開啟「首尾幀」（取決於所選模型是否支援）。

### 為甚麼場景設計圖裡出現了人物？ {#people-in-scene-images}

場景設計圖會要求不出現人物，但圖片模型可能不完全遵循。可以重新生成場景圖，或用圖片編輯移除人物。

### ZaiDrama 支援配音嗎？ {#voice-over-support}

- **對白**由影片模型直接生成人聲。
- **旁白**的交付方式在「項目資訊」的劇集參數裡選擇：後期配音（預設，成片不含旁白人聲）或 TTS 配音（平台合成旁白）；配音模型、音色和語速在項目設定的「旁白配音」裡調整。
- 旁白片段的播放器可以在「原音成片」和「TTS 疊加」之間切換。

### 能調整字幕樣式嗎？ {#subtitle-style}

可以。在「項目資訊 → 字幕樣式」裡調整字號、垂直位置、顏色和字體，預覽所見即燒進成片的樣子，從下一次合成起生效。

## 創意畫布 {#creative-canvas}

### 創意畫布是甚麼？和項目有甚麼區別？ {#canvas-vs-project}

創意畫布是屬於你個人的自由畫布，用節點擺放文字、圖片、影片和音訊，並直接在節點上生成。它不掛在項目下，沒有劇本、批次和成片交付；想完整拍一部多集短劇用項目，想自由試驗畫面或做幾段獨立影片用畫布。兩者透過全域資產庫共享素材。詳見[創意畫布](./canvas.md)。

### 畫布裡的 Zai 會直接花錢嗎？ {#canvas-approval}

預設不會：Zai 每次要花錢生成時先彈出審批條，寫明預計費用（美元）和餘額，由你確認。你可以把審批方式改為「直接生成」，或在審批條上勾選「本輪後續自動確認」，讓本輪剩下的生成在累計 $0.20 的上限內不再逐張確認。刪除節點、清空畫布這類不可撤銷的操作始終需要確認。

### 畫布能分享或備份嗎？ {#canvas-share-export}

- 「分享」可以生成唯讀連結，對方無需登入即可查看，你可以隨時撤銷；
- 畫布可以匯出為 zip，也可以從 zip 匯入；
- 「歷史版本」可以預覽、命名、恢復快照，或另存為新畫布。

## 費用、資料與下載 {#cost-data-export}

### 在哪裡查看餘額和費用？ {#view-and-control-cost}

頂欄的餘額徽章顯示目前美元餘額，點擊可以查看使用明細；賬戶選單的「賬單與餘額」有可用餘額、凍結中的金額、餘額明細和購買記錄，也可以在那裡增值。餘額顯示 2 位小數（向下截斷），每筆扣費等明細顯示 4 位小數。每日登入獎勵和推薦獎勵在「福利中心」。

### 能下載哪些內容？ {#project-zip-vs-full-backup}

- **成片影片**：批次頁「審改」檢視的「本整合片」→「下載」；
- **可編輯套件**：影片片段播放器的「下載可編輯套件」，一個 zip，內含影片、旁白音訊、字幕（`.vtt` / `.srt`）和說明檔案，便於在其他剪接軟件裡繼續加工；
- **旁白音訊**：旁白的歷史版本裡「下載音訊」。

平台不提供整個項目的 ZIP 匯出。

### 可編輯套件為甚麼缺少片段？ {#project-export-missing-clips}

可編輯套件只包含已經成功生成的內容。缺少的片段請先在批次頁查看失敗原因，重拍或補生成後再重新下載。

### 有手機 App 嗎？ {#mobile-app-support}

ZaiDrama 是 Web 應用程式，目前沒有獨立的 iOS 或 Android 原生 App。手機可以透過瀏覽器存取，但審閱批次、編輯畫布更適合在桌面端進行。

### 可以商用或二次開發嗎？ {#commercial-use}

ZaiDrama 的原始碼按 AGPL-3.0 發佈，原始碼存放庫請參閱 [GitHub](https://github.com/z55183980-gif/zaidrama)。

## 效果與成本最佳實踐 {#quality-and-cost-best-practices}

1. 先拍少量片段，驗證畫風、角色和節奏，再擴大範圍。
2. 先確定角色定妝圖和造型，再批量出分鏡和影片。
3. 讓相鄰片段保持地點、時間、服裝和角色描述一致。
4. 只讓目前片段引用真正需要的資產，避免參考圖過多稀釋約束。
5. 單個片段有問題只重拍這一段；滿意的版本及時鎖定。
6. 以「賬單與餘額」的餘額和明細規劃生產範圍。
