# ZaiDrama 的模型與能力 {#providers}

本頁說明在 ZaiDrama 中如何選擇模型、了解能力與處理生成問題。想在自己的程式裡直接調用平台上的模型，見 [API 快速開始](../api/quickstart.md)。

在 ZaiDrama 裡創作無需準備第三方 API 密鑰。ZaiDrama 按**用途**為每一次調用挑選模型，你只在少數地方從平台開放的候選中做選擇。

## 1. 按用途選模型 {#model-usages}

每一次模型調用都屬於一個固定用途：

| 類別 | 用途 | 用來做甚麼 |
| --- | --- | --- |
| 文本 | 簡單任務 | 源文概述、風格圖分析、一致性檢查 |
| 文本 | 複雜任務 | 劇本、批次規劃、畫布寫作 |
| 文本 | 畫布助手 | 創意畫布裡替你動手的 Zai |
| 文本 | 畫布看圖聽聲 | 畫布 Zai 查看節點裡的圖片、影片、音頻 |
| 文本 | 聯網檢索 | 畫布 Zai 需要實時信息時聯網查詢 |
| 圖片 | 文生圖 | 角色圖、場景圖、分鏡圖等純文字出圖 |
| 圖片 | 圖生圖 | 帶參考圖的出圖與圖片編輯 |
| 影片 | 圖生影片 | 分鏡首幀驅動的影片與宮格 |
| 影片 | 參考生影片 | 用角色、場景、道具或產品參考圖直接生成影片 |
| 音頻 | 旁白 | 旁白配音與角色聲音試聽 |

使用默認選擇時，平台會為對應用途選擇當前可用的模型。

## 2. 你能在哪裡選模型 {#user-model-selection}

| 位置 | 能選甚麼 |
| --- | --- |
| 項目信息 → 劇集參數 → 自動模式 | 不選模型，只選「影片質量」（快速 / 標準 / 高質量）和畫面比例，平台按質量檔挑選模型 |
| 項目信息 → 劇集參數 → 專業模式 | 為圖生影片、參考生影片、文生圖、圖生圖分別選模型和分辨率；默認「跟隨全局路由」 |
| 項目設置 → 旁白配音 | 默認旁白配音模型、旁白音色和語速 |
| 創意畫布 → 節點生成面板 | 這一次生成使用的模型 |

- 下拉菜單顯示該用途當前可選的模型。
- 項目裡指定的模型暫時不可用時，界面會提示「項目指定的模型此刻不可用」，可以改回「跟隨全局路由」。
- Zai 的對話模型和其他文本用途由平台配置，用戶不能選擇。
- 個人「設置」頁沒有模型選項。

首次製作建議先用少量片段驗證風格和效果，再擴大範圍。

## 3. 能力邊界 {#capability-boundaries}

平台按具體模型聲明能力，而不是按供應商整體推斷。下面是能力類別，某個模型具體支持哪些，以生成面板和下拉裡實際可選的項為準：

- **文本**：結構化輸出、看圖（圖像輸入）；
- **圖像**：文生圖、圖生圖（帶參考圖出圖與編輯），支持的分辨率與比例；
- **影片**：圖生影片（首幀驅動，部分模型支持尾幀）、參考生影片（多參考圖，數量和類型因模型而異）、參考音頻、支持的時長、分辨率和比例；
- **影片音軌**：有的模型可以選擇是否生成音軌，有的總是帶聲音，有的總是無聲；
- **語音**：TTS 與可選音色；語速在項目設置或畫布語音節點裡調整。

請求超出模型聲明的能力（例如給不支持尾幀的模型傳尾幀）會在提交前被明確拒絕，不會靜默換成你沒選的模型。

## 4. 費用與額度 {#credits-and-usage}

用戶以賬戶菜單「賬單與餘額」中的可用餘額和餘額明細為準。平台會記錄每次生成的用途、模型、狀態和費用（美元）；每次生成按「費率 × 用量」扣費，精確到 $0.0001，最低 $0.0001。扣費結果以餘額明細為準。

遇到餘額不足或扣費異常時，記下項目名稱和發生時間，通過「幫助與反饋」聯繫在線客服，不要重複點擊生成或嘗試繞過額度檢查。

## 5. 故障排查 {#troubleshooting}

### 用戶側 {#user-troubleshooting}

- **下拉裡沒有某個模型**：該用途未提供這個模型，或模型暫時不可用；
- **項目指定的模型不可用**：改回「跟隨全局路由」，或換一個候選；
- **生成失敗**：先看對話或批次頁裡寫明的失敗原因，只重拍受影響的片段；
- **排隊過久**：任務由平台統一調度，請勿重複提交；
- **餘額不足**：到「賬單與餘額」查看餘額和明細。
