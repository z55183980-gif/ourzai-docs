# ZaiDrama 入門教學 {#getting-started}

本教學帶你在 ZaiDrama（AI 短劇創作應用，<https://zaidrama.com>）裏完成第一部短劇：從一句話或一份劇本開始，和 Zai 把需求磨成方案，確認開拍報價，再到拿到可下載的成片。打開網站並登入即可開始，無需安裝軟件或準備第三方 API 密鑰。

## 你將完成甚麼 {#what-you-will-build}

完成教學後，你將能夠：

1. 註冊並登入統一平台賬戶；
2. 在首頁用一句話、一段小説或劇本、參考圖啟動項目；
3. 和 Zai 在同一條對話裏形成創作簡報、世界模型與製作藍圖；
4. 確認開拍報價，讓 Zai 按批次推進分鏡、影片和成片；
5. 在看板和批次頁追蹤進度，對不滿意的片段局部重拍；
6. 預覽並下載成片與可編輯包。

## 預計時間與費用 {#time-and-cost}

- 發送第一句話、建立項目和討論方案不產生費用；圖片、影片和音頻生成才從餘額扣費（美元）。
- 影片生成耗時取決於片段數量、平台隊列和所用模型。
- 餘額、凍結中的金額和扣費明細在賬戶選單的「賬單與餘額」查看；開拍前確認卡會寫明這次要花多少。
- 建議第一次只用少量內容，或對 Zai 説「先拍前兩段」，驗證風格和效果後再擴大範圍。

## 1. 註冊並登入 {#create-account}

### 1.1 註冊或登入 {#sign-in}

在落地頁點「開始創作」或「登入 / 註冊」：

- **登入**：在登入彈窗輸入電郵或用户名和密碼。
- **註冊**：在「創建你的 ZAI 賬户」頁面用電郵驗證碼註冊；密碼至少 6 位，需同時包含字母和數字。
- **忘記密碼**：在登入彈窗點「忘記密碼？」，用電郵驗證碼重設。
- **從 ZAI 平台進入**：在 ourzai.com 點「創作工作台」進入；已有有效登入狀態時無需再次輸入密碼。

ZaiDrama 與 ZAI 平台共用同一個賬户，在官網或開發者控制台註冊的賬户可以直接登入。登入狀態過期或需要安全驗證時，按頁面提示重新登入。賬户與餘額的完整説明見[賬户、餘額與支援](../platform/account.md)。

### 1.2 賬户選單 {#account-services}

側欄左下角的賬户選單提供：

| 入口 | 用途 |
| --- | --- |
| 個人中心 | 頭像、暱稱、電郵綁定、修改密碼、登入裝置、註銷賬户 |
| 福利中心 | 每日登入獎勵、推薦獎勵 |
| 賬單與餘額 | 可用餘額、餘額明細、購買記錄、增值 |
| 儲存空間 | 已用容量、各項目佔用、清理歷史版本 |
| 幫助與反饋 | 在線客服 |
| 設定 | 外觀與語言、API 權杖（供外部工具存取 ZaiDrama，與開發者控制台的 API 密鑰不同）、關於、診斷紀錄 |

頂欄的餘額徽章會顯示目前美元餘額，點擊可查看使用明細。

## 2. 從首頁啟動項目 {#start-conversation}

### 2.1 説出你想做的 {#creative-intent}

首頁標題是「今天想把甚麼做成影片？」。在輸入框裏寫下任意一種起點：

- 一個故事點子或一句創作目標；
- 一段小説、劇本、大綱或產品介紹；
- 你對畫風、時長、比例、受眾的要求。

輸入框下方的快捷入口可以幫你開頭：「上載小説 / 劇本」直接打開檔案選擇；「我有一個點子」「寫一集爽劇開篇」「給產品拍條廣告」只把一句開頭填進輸入框，不會替你發送。

### 2.2 附上素材 {#source-intake}

用輸入框的迴形針按鈕、拖拽或貼上新增附件：

- **圖片**：PNG、JPG、WebP，單張不超過 5MB，一次最多 5 張。圖片會發給 Zai 看，適合做角色、場景或商品參考。
- **小説 / 劇本檔案**：`.txt`、`.md`、`.docx`、`.epub`、`.pdf`，單個檔案不超過 50MB，一次最多 5 個，發送後存成項目的源文。
- **長段貼上**：一次貼上較長的文字（約 800 字或 16 行以上）會自動收成一張「貼上的文字」卡片，發送後同樣存成源文，並佔用一個檔案名額；不想這樣可以點「轉回正文編輯」。

輸入框單條訊息上限 2 萬字，更長的內容請作為檔案附上。掃描版 PDF 沒有可提取的文字，需要先做 OCR；舊式 `.doc` 請先轉成 `.docx`。

### 2.3 發送即建項目 {#create-project}

發送第一句話時，ZaiDrama 會建好項目並進入項目頁，這句話和附件會在項目裏的 Zai 對話中繼續。首頁不另存聊天記錄，一個項目只有一條 Zai 對話，從討論方案一直延續到成片。項目標題先顯示為「未命名項目」，Zai 讀完源文後會替它起名。

## 3. 認識項目頁 {#project-workspace}

項目頁分為三塊：

- **主區：Zai 對話**。你在這裏提需求、回答提問、確認報價，Zai 在這裏匯報每一步做了甚麼。
- **右側：工作台**。可拖寬、可收起。「看板」常駐最左；點「+」可以打開「批次」「文稿」「資產庫」「項目資訊」，項目有商品時還會出現「產品」。每個頁面是一個可關閉的標籤。
- **左側：製作進度大綱**。按「前期準備 / 劇本製作 / 資產準備 / 逐集製作 / 成片交付」顯示目前進行到哪一步。

剛進項目時，工作台會自動翻到 Zai 目前這一步對應的頁面；之後你切到哪一頁由你決定。頂欄中間的狀態標籤（如「生產中 · 分鏡 8/11」「需要你決定」）點一下就能回到看板。

## 4. 和 Zai 確定方案 {#confirm-project}

### 4.1 劇本體檢與提問 {#script-review}

如果你給了小説或劇本，Zai 會先讀完並做一次劇本體檢：挑出缺集、邏輯漏洞、閒置角色、沒有鋪墊的轉折等問題（最多 5 條，每條附原文和改法），再問你要不要改。

Zai 需要你拍板時會彈出提問卡，停在輸入框上方：選項可能標有「推薦」，可以用數字鍵直接選，按 Esc 跳過；選項都不合適就直接在輸入框裏寫，也算回答（一次問好幾個時，卡上另有「其他…」給某一問單獨寫）。選「我有劇本 / 小説」這類選項會把你帶到輸入框，貼正文或點 + 上載檔案即可。

### 4.2 三層方案 {#choose-content-mode}

Zai 把需求整理成三層可修改的方案：

- **創作簡報**：要做甚麼、給誰看、在哪發、多長、甚麼語氣；
- **世界模型**：角色（身份與造型）、場景、道具、商品、視覺風格與連續性規則；
- **製作藍圖**：把作品拆成若干片段，每段寫明類型、時長、出場人物和視覺/聲音方向。

項目不需要先選「短劇 / 説書 / 廣告」這類模式，也不需要先選「分鏡 / 參考圖」路線：每個片段各自決定怎麼生產，同一部作品可以混用。導入小説或劇本後，Zai 還會推薦項目風格（仿真人、3D 漫劇或 2D 漫劇），預設仿真人。

整理方案、分析源文、首次寫劇本這類不花錢的動作，Zai 會直接做完再告訴你。只有它要覆蓋你親手改過的內容時，才會彈卡請你確認。詳見[創作流程](./workflows.md)。

### 4.3 採納方案與開拍確認 {#proposal-gate}

方案成形後，對話框上方會出現確認橫幅：

- **採納製作方案**：劇本或資產圖還沒就緒時，先採納方案，本步不產生費用。
- **開拍確認**：卡片標題寫明「開拍要花 $N」（美元），點「看明細」可以看到片段數、影片秒數、分鏡數、設定圖數，以及餘額變化和未包含的項目（例如返工）。點「批准並開拍」後，這筆額度記在目前項目上，額度內的步驟會自動執行，不再逐步打斷你。

開拍可以只拍一部分：對 Zai 説「先拍第一集」或「只拍前兩段」，報價和額度只算這些片段，之後的分鏡和影片都守這個範圍。

確認卡擺着時，你在輸入框裏説一句新的話，這張卡就會作廢，Zai 按你的新要求重來。

## 5. 審閲文稿與資產 {#review-script-assets}

### 5.1 文稿 {#script-documents}

工作台的「文稿」頁列出「原始文稿」和按「第 N 批」分組的劇本，每批包含「批次原文」和「正式劇本」。點「上載來源檔案」可以繼續補充素材。

打開正式劇本可以看到每個片段的內容。角色有多套造型時，每一段都要在「造型」下拉裏選一套，沒選的段會顯示「未選擇」，出分鏡前必須補上。

劇本由 Zai 直接寫好，寫完你可以隨時查看和修改；你改過的內容，Zai 之後要覆蓋時會先徵得你同意。

### 5.2 角色、場景和道具 {#asset-review}

「資產庫」頁按角色、場景、道具分組，可以篩選、新增，或「從資產庫選擇」重用跨項目的資產：

- **定妝圖**：每個角色一張，包含頭肩特寫和正面、側面、背面全身，是後續出圖的身份錨點。
- **造型**：一個角色可以有多套造型（髮型、上裝、下裝、鞋、配飾）。主造型之外的變體以主造型定妝圖為身份參考，因此要先生成主造型定妝圖。
- **聲音**：可以為角色設定參考音頻，或用 TTS 生成一段。
- **歷史版本**：資產圖、分鏡、影片都能「切換到此版本」；「鎖定目前版本」後，重新生成的結果只進入歷史候選，不會取代目前版本。

你在資產庫新增的條目會自動告訴 Zai。資產定義變化後，已經生成的分鏡和影片不會被靜默覆蓋，而是標記為「比目前內容舊」，是否重做由你決定。

## 6. 追蹤生產 {#run-production}

### 6.1 看板與狀態 {#production-gates}

開拍後，「看板」變為生產看板：

- **各站進度**：方案與劇本、設定圖、分鏡、影片、成片五站；
- **需要你決定**：例如某一步超出額度在等確認，或某一站有幾個沒做成；
- **最新產出**：剛生成的內容帶「新」標記。

對話裏的每一步會以提交卡片顯示結果，例如「生成影片 · 已完成」「動用開拍額度」「用時 …」；部分失敗時會寫明「N 個裏 M 個沒成，其餘已經做好」。

### 6.2 批次頁 {#task-status}

生產以批次為單位推進：一批的分鏡和影片都做完，就進入下一批。「批次」頁的標題欄可以切換上一批 / 下一批，並有兩種檢視：

- **預覽**（預設）：連播這一批，鏡頭腳本隨播放逐行捲動；每段可以查看發給影片模型的提示詞，下方有畫面軌與音頻軌。沒跑成的段會寫明原因，並提供「再試一次」。
- **審改**：本集成片、製作狀態、本批角色、分鏡圖、候選審片和影片片段。

想暫停、繼續或取消生產，直接在對話裏告訴 Zai。任務狀態包括排隊中、生成中、已完成、已失敗、已取消和已中斷；平台重啟時，已提交給模型服務的影片會接着等結果，少量進行中的圖片任務可能標記為中斷，需要重新生成對應的那一項。

### 6.3 局部重拍 {#rerun-and-versions}

對某一段不滿意時，在對話裏説清哪段、怎麼改（例如「第 3 段她再冷一點」）。Zai 會給出舊 → 新的改法對照，確認後只重做這一段影片。

- 重拍和自動返修從單獨的返工額度出，不佔用開拍額度；返工額度不夠時會再彈卡確認。
- 自動校驗判定失敗的產物會被自動返修，同一問題返修到上限後交回你決定。
- 「候選審片」按評分列出候選版本，可以「選定並鎖定」「退回」「再出一條」或「按建議返修」。

你在工作台上直接做的改動（例如切換版本、重新合成）會在對話裏留一行記錄，Zai 下次開口前會知道。

## 7. 預覽與下載 {#preview-and-export}

批次頁「審改」檢視頂部的「本集成片」提供：

- 預覽成片並開關「成片字幕」；
- 「下載」成片影片；
- 「歷史版本」查看以前的成片，標「目前」的是正在使用的版本；
- 「重新合成」。

影片片段的播放器提供：

- 旁白片段可切換「原音成片」與「TTS 疊加」；
- 「下載可編輯包」：一個 zip，內含影片、旁白音頻、字幕（`.vtt` / `.srt`）和描述檔案，便於在其他剪接軟件裏繼續加工。

字幕的字號、位置、顏色和字體在「項目資訊 → 字幕樣式」裏調整，從下一次合成起生效。

建議下載需要長期保留的成片和素材。

## 8. 模型與參數 {#provider-boundary}

「項目資訊」頁的「劇集參數」有兩種模式：

- **自動模式**：只選「影片品質」（快速 / 標準 / 高品質）和畫面比例（直屏 9:16 / 橫屏 16:9），模型由平台決定。
- **專業模式**：按用途（圖生影片、參考生影片、文生圖、圖生圖）選擇模型和解析度，預設「跟隨全域路由」；還可以設定是否生成音頻和項目風格。

兩種模式都可以設定旁白交付方式（後期配音或 TTS 配音）和字幕樣式。項目選單的「項目設定…」可以改項目風格和旁白配音模型、音色、語速。Zai 使用的對話模型由平台配置，用户不能選擇。

可選的模型只來自平台目前開放的候選。能力不可用、任務失敗或扣費異常時，先看對話裏的失敗原因；仍無法解決時通過「幫助與反饋」聯絡在線客服。不要在對話裏貼上任何 API Key 或密碼。
