# 創意畫布 {#canvas}

創意畫布是一塊自由擺放靈感、參考和生成結果的無限畫布。你可以在節點上直接生成圖片、影片、文本和語音，把一張圖接到下一個節點繼續加工，也可以讓畫布裏的 Zai 幫你改圖、出影片。它適合試風格、做概念圖、打磨單個鏡頭，或者做一條不需要完整劇本的短片。

## 1. 畫布和項目的關係 {#canvas-and-projects}

- 畫布屬於你個人，不掛在任何項目下；項目也不會讀取畫布內容。
- 畫布不是第二條生產管線：它沒有劇本、批次和成片交付，生成結果不會自動進入項目。
- 兩者通過**全局資產庫**互通：畫布裏的圖片可以「存入資產庫」，項目在資產庫頁用「從資產庫選擇」重用；畫布側欄的「資產」標籤也能把資產庫裏的內容放到畫布上。

需要把一個故事完整拍成多集短劇時，用項目；想先自由試驗畫面、或只做幾段獨立影片時，用畫布。

## 2. 創建與管理畫布 {#manage-canvases}

在側欄點「創意畫布」進入畫布列表。第一次進來、還沒有任何畫布時，會直接打開一張空白畫布。

列表按「今天 / 最近 7 天 / 更早」分組，卡片寫明畫布上有甚麼。在列表裏可以：

- 在頂欄搜索畫布名稱或內容；
- 「新建畫布」，或從已有畫布「複製」一份；
- 「導入」一個畫布 zip，或把畫布「導出」為 zip（導入時認不出的包只會導入其中的媒體）；
- 「選擇」多張畫布批量導出或刪除；
- 重命名、刪除畫布。

畫布會按內容自動起名：第一次放進有文字的內容時按第一個節點起名，Zai 在畫布上做過東西後按這一輪的需求起名；你改過的名字不會被覆蓋。新建後甚麼都沒做就關掉的空白畫布會被自動丟棄，不會留在列表裏。

每張畫布在新的瀏覽器標籤頁中打開。畫布會自動保存，頂欄顯示「已保存 / 保存中… / 未保存」；同一張畫布在兩個視窗裏同時編輯發生衝突時，會提示「與另一視窗的改動衝突」。

## 3. 節點與連線 {#nodes}

工具欄提供：

- **選擇 / 抓手**：選中節點或拖動畫布；
- **添加節點**：文本、圖片、影片、音頻；多個節點可以放進一個分組；
- **上傳文件**：PNG、JPG、WEBP、MP4、WEBM、MP3、WAV，圖片不超過 20MB，影片不超過 200MB，音頻不超過 30MB；
- **使用已有素材**：從你上傳或生成過的素材中挑選；
- **預設**：例如「腳本生成器」「角色三視圖」，一次擺好一組常用節點；
- **畫布設定**：預設畫幅、預設清晰度、背景樣式，以及「清空畫布」。

節點之間的連線表示輸入關係：把圖片節點連到影片節點，它就成為影片的首幀或參考。

側欄有「畫布」「資產」「提示詞」三個標籤。「提示詞」裏有公共合集和「我的」提示詞庫。

## 4. 在節點上生成 {#generate}

選中節點即可打開生成面板：

| 生成 | 可設置 |
| --- | --- |
| 生成圖片 | 生成模型、清晰度、生成數量、畫面比例、風格；比例選「智能」時按第一張參考圖取最接近的比例 |
| 生成影片 | 連一張圖作首幀（成片通常跟隨首幀的比例）；連兩張及以上的圖時全部作為參考圖，用 `@` 指明誰是誰，成片按所選比例出；打開「首尾幀」時前兩張作首幀和尾幀；解像度、時長、是否「生成音頻」 |
| 生成文本 | 寫作要求 |
| 語音合成 | 音色、語速 |

生成完成後，節點上的快捷操作可以接着「生成影片」「生成圖片」「配旁白」「續寫下一鏡」。

圖片節點還提供反推提示詞、裁剪、切圖、放大、局部編輯、多角度、截取影片的首幀 / 當前幀 / 尾幀、存入資產庫等工具。其中裁剪、切圖和放大在瀏覽器裏完成，不產生費用。

可選的生成模型來自平台為對應用途開放的候選，見[模型與能力](./models.md)。

## 5. 畫布裏的 Zai {#canvas-zai}

畫布右下角的 Zai 視窗可以拖動和縮放，雙擊回到右下角。它看得見這張畫布，也能替你改：

- **作用範圍**：選中節點時只處理「已選 N 個節點」，否則處理「整張畫布」；
- **看素材**：能查看節點裏的圖片、影片和音頻；
- **聯網檢索**：需要時會檢索網絡資料，檢索回來的內容只作參考材料；
- **備忘錄**：面板頂部的備忘錄每一輪 Zai 都會讀到，你和 Zai 都可以編輯；畫幅、風格、清晰度等畫布預設設置會自動帶到新畫布，不需要寫進備忘錄；
- **撤銷這一輪**：一鍵撤回 Zai 這一輪對畫布的全部修改。

畫布 Zai 不預設你在拍短劇，寫故事、做海報、做產品圖都可以。它使用的對話模型由平台配置。

### 5.1 生成前確認 {#approval}

Zai 要花錢生成時，默認先彈出審批條，寫明預計費用（美元）和餘額，你點「確認生成」後才執行；點「在畫布上查看」可以先看它要改哪些節點。

- 在 Zai 面板的審批方式裏可以改為「直接生成」，之後 Zai 不再逐次請示。
- 審批條上勾選「本輪後續自動確認」，本輪剩下的生成在累計 $0.20 的上限內不再逐張彈卡，超出上限的那一次照常確認。
- 刪除節點、清空畫布等不可撤回的操作始終需要確認。

## 6. 歷史版本 {#history}

頂欄的「歷史版本」可以預覽、命名或恢復畫布快照：

- 編輯時平台會定期自動留存版本；刪除內容、恢復版本和 Zai 修改畫布之前也會各留一份；
- 「存為版本」並命名的版本不會被自動清理；
- 可以「恢復此版本」，也可以「另存為新畫布」。

## 7. 分享 {#share}

頂欄的「分享」可以生成**只讀連結**：拿到連結的人無需登入即可查看這張畫布，但不能編輯。你隨時可以「撤銷連結」，撤銷後連結立即失效。
