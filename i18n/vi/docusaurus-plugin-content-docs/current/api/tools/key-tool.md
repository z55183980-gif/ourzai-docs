# Công cụ quản lý khóa {#key-tool}

Công cụ quản lý khóa là ứng dụng máy tính do ZAI cung cấp. Công cụ này quản lý tập trung các API key của bạn và thiết lập kết nối ZAI API cho Claude và Codex, nên bạn không cần tự chỉnh sửa tệp cấu hình. Bạn vẫn tạo key trong mục **API keys** của [Developer Console](https://ourzai.com/console).

## Tải xuống {#download}

[Mở trang tải xuống](https://ourzai.com/tools/key-manager) để chọn Windows hoặc macOS.

Sau khi cài đặt, đăng nhập để nhập khóa hoặc thêm thủ công, rồi chọn ứng dụng và mô hình để khởi chạy. Bạn cần cài Claude hoặc Codex riêng.

## Thiết lập thủ công {#manual}

Để thiết lập một công cụ mà không dùng công cụ quản lý khóa, hãy làm theo hướng dẫn tương ứng:

- [Claude Code](./claude-code.md)
- [Claude Desktop](./claude-desktop.md)
- [Codex CLI](./codex-cli.md)
- [Ứng dụng Codex](./codex-app.md)
