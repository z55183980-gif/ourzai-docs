# Memory and Data {#memory-and-data}

After a conversation, Zai saves details as long-term memories to help future chats pick up where you left off. These memories are not a word-for-word transcript, and not everything you say appears in the memory bank right away.

## View and manage memories {#manage-memory}

1. Open **Settings → Privacy & data**.
2. Select **View and manage memories** to open the memory bank.
3. Review saved content. Correct inaccurate entries or delete entries you do not want to keep.
4. Check that your changes have saved. If an action fails, reload the page and review the entry before trying again.

Chat history and long-term memories are managed separately. View or delete chat messages in the chat window.

## Pause new memories {#pause-memory}

Turn on **Pause memory** under **Settings → Privacy & data**. While it's on, Zai won't add anything from new chats to long-term memory. Zai can still use existing memories.

Turn it off to let Zai save new memories again. Pausing memory does not clear existing memories or delete chat history.

## Export data and import memories {#export-and-import}

- **Export data**: under **Privacy & data → Manage data**, select **Download** beside **Export data** to save an archive containing chats, memories, diary entries, and other data.
- **Import memories**: choose this option on the same page and select an export file as prompted. Import adds memories while keeping existing ones. It **does not restore chats or diary entries**.

Export files contain your personal conversations, so keep them in a secure location. The page will show whether your import or export succeeded.

Voice records in the export contain text, not audio recordings. Documents delivered in chat and stored on the client are outside the server export; save them separately if you need them. The export is not a complete backup of the application state.

## Start over {#start-over}

**Start over** in **Privacy & data** clears chats, memories, notes, and diary entries. Your account, membership, appearance, voice, and relationship settings are retained.

This cannot be undone. Export your data first if you want to keep a copy, then review what will be deleted before confirming. Importing memories will not restore your chat history.

Deleting an account and starting over are separate actions. See [Account, Balance, and Support](../platform/account.md) for account security, terms, and help.
