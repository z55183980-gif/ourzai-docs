# Key management tool {#key-tool}

The key management tool is a desktop app from ZAI. It keeps your API keys in one place and sets up ZAI API access for Claude and Codex, so you do not have to edit configuration files by hand. You still create keys under **API keys** in the [developer console](https://ourzai.com/console).

After installation, sign in to import keys or add one manually, then choose a client and model to launch. Install Claude or Codex separately.
