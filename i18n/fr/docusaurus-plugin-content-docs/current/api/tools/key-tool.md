# Outil de gestion des clés {#key-tool}

L'outil de gestion des clés est une application de bureau proposée par ZAI. Il regroupe vos clés API au même endroit et configure l'accès à l'API ZAI pour Claude et Codex, sans que vous ayez à modifier les fichiers de configuration à la main. Les clés se créent toujours dans la section **API keys** de la [console développeur](https://ourzai.com/console).
