# チャットと音声 {#chat-and-voice}

[Zai](https://zai.gg)では、テキスト入力、音声メッセージの送信、Zaiへの直接通話が可能です。

## テキストチャット {#text-chat}

チャットボックスに入力してメッセージを送信します。Zaiが返信している間も会話を読むことができます。現在の応答が不要になった場合は、停止ボタンを使用して現在のタスクを終了します。

接続が切断された場合は、画面の指示に従って再送信してください。問題が解決しない場合は、発生時刻とエラーメッセージを記録し、[サポート](../platform/account.md#support)までお問い合わせください。

## 音声を使用する3つの方法 {#voice-options}

| 機能 | 使用方法 | 説明 |
| --- | --- | --- |
| 音声メッセージ | メッセージボックス横のマイクボタンを選択し、メッセージを録音して送信します | 入力する代わりに話してメッセージを送信できます |
| 音声返信 | 音声モードに切り替えると、Zaiの返信を音声で聞くことができます | 音声返信の利用枠を使用します |
| 音声通話 | **音声通話 (Voice call)**を選択し、マイクへのアクセスを許可して、リアルタイムで会話します | ライブ会話を開始し、音声通話の利用枠を使用します |

音声返信と音声通話にはそれぞれ別の利用枠があります。音声メッセージの録音はリアルタイム通話を開始しません。

## 音声返信の調整 {#voice-replies}

1. チャットを音声モードに切り替えます。
2. 音声モードのオプションで、返信を自動的に再生するかどうかを選択します。
3. **設定 → 音声 (Settings → Voice)**を開き、音声の選択、音量の調整、現在の期間の音声返信の残り時間を確認します。

読み上げよりも読みたい場合は、テキストモードに戻してください。音声返信の時間がなくなると、Zaiはテキスト返信に切り替わり、メッセージで通知されます。リセット日と追加パックについては、[プランと利用状況](./plans-and-usage.md)をご覧ください。

## 音声通話の発信 {#voice-call}

1. チャット画面で**音声通話 (Voice call)**を選択します。
2. ブラウザが要求したときにマイクへのアクセスを許可し、マイクが正常に動作することを確認します。
3. 通話中はマイクのミュート切り替えとZaiの音声のオン・オフができます。パソコンで最小化した通話は、最小化された通話バーを押して戻します。人物の下にある通話ボタンは押さないでください。通話中に押すと切断されます。
4. 終了するには**End**または**Hang up**を選びます。スマートフォンでは通話画面の操作ボタンを使ってください。ウィンドウの最小化手順はパソコンのみです。

通話時間がなくなった場合は、プランページでリセット日と追加パックを確認してください。通話が一時的に利用できない場合は、時間をおいて再度お試しください。

## 音が出ない、または録音できない場合 {#troubleshooting}

- **録音できない**: ブラウザでのサイトのマイク権限と、システムで選択されている入力デバイスを確認してください。
- **返信が聞こえない**: デバイスとページの音量、タブがミュートされていないか、音声返信が有効になっているかを確認してください。自動再生がブロックされている場合は、手動で再生してください。
- **通話でZaiの声が聞こえない**: 通話の音声コントロールを確認してください。マイクのミュートは自分の声のみを制御します。
- **時間が残っているのに動作しない**: エラーメッセージを記録し、更新して再試行してください。問題が解決しない場合はサポートにお問い合わせください。

音声の選択については、[外観、音声、関係性](./appearance-and-relationship.md#voice)をご覧ください。
