# Zai に出会う — はじめに {#getting-started}

Zaiは、ZAIプラットフォーム上のAIコンパニオンです。日々の出来事を話したり、心に浮かんだことを共有したり、コンパニオンの外見やあなたとの関係性を選んだりできます。音声での返答を聞いたり、音声通話で会話したりすることも可能です。

**[Zaiとチャットする](https://zai.gg)**

## 最初の会話を始める {#first-chat}

1. [zai.gg](https://zai.gg)を開き、外見と名前を確認して、友達・恋人・コーチの関係を選びます。恋人を選ぶ場合は、18歳以上であることの確認が必要です。
2. **Start**を選び、ログインまたはアカウント登録を行います。既存のアカウントでは、保存済みの外見・名前・関係が優先されます。
3. 新しいアカウントでは、初対面のプロローグが始まります。最後まで進めるかスキップすると、自由に会話できます。
4. 入力欄にメッセージを入力して送信します。例：「今日は少し疲れたから、話し相手になってくれる？」
5. 音声返信に切り替えてZaiの声を聞くか、**音声通話 (Voice call)**を使ってリアルタイムで会話します。操作や使い方については、[チャットと音声](./chat-and-voice.md)をご覧ください。

初対面のプロローグを完了して返答を選んだ場合、後日の訪問で条件を満たすと、Zaiがその言葉に触れることがあります。予約されたプッシュ通知ではありません。外見・名前・声・関係は、後から設定で変更できます。

## アカウントとアクセス {#account-and-access}

Zaiは、ZAIプラットフォームのアカウントを使用します。別の製品を開く際に再度サインインが必要になる場合がありますが、製品ごとに個別のアカウントを作成する必要はありません。登録、パスワードの回復、サポートについては、[アカウント、残高、サポート](../platform/account.md)をご覧ください。

プランページでは、無料プランとZai Plusに含まれる内容（音声利用枠を含む）を確認できます。これらの特典は、APIやZaiDramaで使用する米ドル残高とは別のものです。詳細は[プランと利用状況](./plans-and-usage.md)をご覧ください。

## さまざまな製品におけるZai {#which-zai}

- **zai.ggのZai**：本書で説明するAIコンパニオンで、日常会話、関係性の設定、メモリー管理を行います。
- **公式ウェブサイトおよび開発者向けコンソールのZai**：製品情報、ドキュメント、APIガイダンスを提供するプラットフォームアシスタントです。
- **ZaiDramaのZai**：プロジェクトやキャンバスタスクを支援するクリエイティブアシスタントです。

各バージョンのZaiには異なる役割があります。本書の手順はzai.ggに適用されます。
