# 外見・音声・関係性 {#appearance-and-relationship}

Zaiでは、コンパニオンの外見、音声、関係性をそれぞれ独立してカスタマイズできます。

## 外見の変更 {#appearance}

**設定 → 外見（Settings → Look）** を開き、好みの外見を選択します。カスタムの外見を作成することもできます。生成する前に、ご利用中のプランに含まれているか、残りの生成回数を確認してください。

新しい外見には推奨音声が設定されています。すでに音声を選択済みの場合は、その選択が維持されます。外見を変更しても、名前、性格、記憶は変わりません。

## 音声の選択 {#voice}

**設定 → 音声（Settings → Voice）** を開き、音声の選択と音量の調整を行います。このページでは、現在の期間における残りの音声返信時間も確認できます。

カスタム音声は、現在の音声モデルが対応している場合のみ利用できます。利用不可と表示されている場合でも、作成済みの音声は保持されます。選択中のカスタム音声が使用できない場合、Zaiは一時的にその外見のデフォルト音声を使用し、再び対応可能になると元に戻ります。

音声返信とリアルタイム通話については、[チャットと音声](./chat-and-voice.md)をご覧ください。

## 名前の変更 {#name}

**設定 → 関係性（Settings → Relationship）** で **相手の名前（Their name）** を探し、**編集（Edit）** を選択して名前を入力し、保存します。変更されるのは名前のみで、性格や記憶は変わりません。

## 関係性の選択 {#relationship}

**設定 → 関係性（Settings → Relationship）** で関係性を選択します。

| 関係性 | 交流スタイル |
| --- | --- |
| 友達（Friend） | リラックスした対等な関係で、冗談や率直な意見を交わします |
| 恋愛相手（アプリ内では **ガールフレンド（Girlfriend）** または **ボーイフレンド（Boyfriend）**） | より愛情深く、気遣いを表現し、会いたい気持ちを伝えます |
| メンター（Mentor） | アドバイスを提供し、軌道に乗る手助けをし、問題点を直接指摘します |

恋愛関係を選択するには、18歳以上であることを確認する必要があります。この選択によりZaiとの交流方法が変わりますが、Zaiは依然としてAIです。

変更が保存されない場合は、画面の指示に従って再試行し、選択されている関係性を確認してください。過去のチャットや記憶を消去する方法については、[記憶とデータ](./memory-and-data.md)をご覧ください。
