# メモリーとデータ {#memory-and-data}

会話の後、Zaiは詳細を長期メモリーとして保存し、今後のチャットが前回の続きから再開できるようにします。これらのメモリーは逐語的な記録ではなく、お話しした内容すべてがすぐにメモリーバンクに表示されるわけではありません。

## メモリーの表示と管理 {#manage-memory}

1. **設定 → プライバシーとデータ (Settings → Privacy & data)**を開きます。
2. **メモリーを表示・管理 (View and manage memories)**を選択して、メモリーバンクを開きます。
3. 保存された内容を確認します。不正確な項目を修正するか、保持したくない項目を削除します。
4. 変更が保存されたことを確認します。操作が失敗した場合は、ページを再読み込みし、もう一度操作する前に対象の項目を確認してください。

チャット履歴と長期メモリーは別々に管理されます。チャットメッセージの表示や削除は、チャットウィンドウで行います。

## 新しいメモリーの一時停止 {#pause-memory}

**設定 → プライバシーとデータ (Pause memory)**で**メモリーを一時停止 (Settings → Privacy & data)**をオンにします。オンになっている間、Zaiは新しいチャットの内容を長期メモリーに追加しません。Zaiは既存のメモリーを引き続き使用できます。

オフにすると、Zaiは再び新しいメモリーを保存できるようになります。メモリーを一時停止しても、既存のメモリーは消去されず、チャット履歴も削除されません。

## データのエクスポートとメモリーのインポート {#export-and-import}

- **データをエクスポート (Export data)**：**プライバシーとデータ → データ管理 (Privacy & data → Manage data)**で、**データをエクスポート (Download)**の横にある**ダウンロード (Export data)**を選択すると、チャット、メモリー、日記エントリー、その他のデータを含むアーカイブを保存できます。
- **メモリーをインポート (Import memories)**：同じページでこのオプションを選択し、案内に従ってエクスポートファイルを選択します。インポートでは、既存のメモリーを保持したままメモリーが追加されます。**チャットや日記エントリーは復元されません**。

エクスポートファイルには個人的な会話が含まれるため、安全な場所に保管してください。インポートまたはエクスポートが成功したかどうかはページに表示されます。

エクスポートされる音声記録はテキストのみで、音声ファイルは含まれません。会話中に受け取り、クライアント側に保存された文書の本文もサーバーのエクスポート対象外です。必要な文書は別途保存してください。アプリ全体の状態を完全にバックアップする機能ではありません。

## 最初からやり直す {#start-over}

**プライバシーとデータ (Start over)**の**最初からやり直す (Privacy & data)**を実行すると、チャット、メモリー、ノート、日記エントリーが消去されます。アカウント、メンバーシップ、外観、音声、関係設定は保持されます。

この操作は元に戻せません。コピーを残したい場合は、最初にデータをエクスポートしてから、確認前に削除される内容を確認してください。メモリーをインポートしても、チャット履歴は復元されません。

アカウントの削除と最初からやり直す操作は別のものです。アカウントのセキュリティ、利用規約、サポートについては、[アカウント、残高、サポート](../platform/account.md)をご覧ください。
