# ZaiDrama よくある質問 {#faq}

この記事では、ZaiDrama クリエイションアプリで最もよく寄せられるアカウント、制作、ダウンロードに関する質問を取り上げます。初めてご利用になる場合は、先に[ZaiDrama スタートガイド](./getting-started.md)をご覧になることをおすすめします。プラットフォームのアカウントと残高については、[アカウント、残高、サポート](../platform/account.md)をご参照ください。

## ZaiDrama を使用する前に理解しておくべき機能の境界は何ですか？ {#capability-boundaries}

- メディア生成は、プラットフォームが上流のモデルサービス全体にわたってスケジュールします。生成速度、可用性、コンテンツポリシーは、現在のサービス状況に応じて変わる場合があります。
- Zai はほとんどの手順を自動で進めますが、長編コンテンツの場合は、プラン、キャラクター参照シート、主要セグメントを確認することをおすすめします。ZaiDrama はクリエイターの判断を支援するものであり、判断を代替するものではありません。
- 動画モデルによって、参照画像の枚数、長さ、オーディオトラック、解像度に関する制限が異なります。
- Web サイトを開いてログインするだけで開始できます。ソフトウェアのインストールやサードパーティの API キーは不要です。

## 登録、ログイン、アカウント {#install-deploy-update}

### 一般ユーザーはどのように始めればよいですか？ {#how-to-install}

ランディングページで「創作を始める」をクリックし、統合プラットフォームアカウントで登録またはログインして、ホームページに入ります。入力ボックスに作りたい動画を入力するか、小説、脚本、参照画像を添付します。最初のメッセージを送信するとプロジェクトが作成され、プロジェクトページに移動します。この手順では料金は発生しません。

### ログイン方法は？ パスワードを忘れた場合は？ {#default-login}

- ログインダイアログでは、メールアドレスまたはユーザー名でログインできます。デフォルトのアカウントはありません。まず登録が必要です。
- パスワードを忘れた場合は、ログインダイアログの「パスワードをお忘れですか？」をクリックし、メールの認証コードでリセットします。
- すでにログインしていてパスワードを変更したい場合は、アカウントメニューの「個人センター」に移動し、「パスワード変更」をクリックします。
- ourzai.com から「クリエーションワークスペース」経由で入る場合、有効なセッションがあればパスワードを再入力する必要はありません。ZaiDrama と ZAI プラットフォームは同じアカウントを共有します。

パスワードや認証コードをチャットで誰にも共有しないでください。

### ログイン中のデバイスを確認したり、アカウントを削除したりするには？ {#account-security}

「個人センター」の「ログインデバイス」で、ログイン中のすべてのデバイスを確認し、個々のデバイスで「ログアウト」をクリックできます。「アカウント削除」も個人センターにあります。

### プラットフォームのページが開かない、またはリクエストが失敗する場合は？ {#page-request-failure}

まずネットワーク接続とログイン状態を確認し、ページを更新して再試行してください。特定のプロジェクトまたは生成のみが失敗する場合は、会話またはバッチページに表示される失敗理由を確認してください。継続的に失敗する場合は、アカウントメニューの「ヘルプ＆フィードバック」からオンラインサポートに連絡し、発生時刻と発生したページを記録しておいてください。必要に応じて、「設定 → 診断ログ」から診断ログをダウンロードし、サポートに送信してください。環境ファイルをアップロードしたり、認証情報をチャットに貼り付けたりしないでください。

### プラットフォームはどのように更新されますか？ プロジェクトは失われますか？ {#platform-updates}

Web サイトは自動的に更新されます。ユーザーが更新パッケージをインストールする必要はありません。更新中、すでにモデルサービスに送信された動画は結果待ちのまま続行されます。進行中の少数の画像タスクは中断としてマークされ、再生成が必要になる場合があります。完了した出力が新しいバージョンによって黙って上書きされることはありません。

### プロジェクトはどこに保存されますか？ バックアップ方法は？ {#where-is-data}

プロジェクト、アセット、生成結果はプラットフォームに保存されます。長期的に保存したいコンテンツはダウンロードすることをおすすめします。完成した動画、編集可能パッケージ、ナレーション音声はいつでもダウンロードできますが、プラットフォームはプロジェクトレベルの ZIP エクスポートを提供していません。アカウントと残高のデータはどのダウンロードにも含まれません。

### ストレージがいっぱいの場合は？ {#storage-full}

アカウントメニューの「ストレージ」で、容量制限とプロジェクトごとの使用量を確認してください。「履歴をクリーンアップ」を使用して、不要になった履歴バージョンを削除します（履歴バージョンのみが削除され、現在使用中のバージョンは保持されます）。

## Zai との会話 {#setup-and-assistant}

### 制作を開始する前に設定する必要がある認証情報は何ですか？ {#required-credentials}

ありません。一般ユーザーは統合プラットフォームアカウントのみが必要です。Zai の会話、テキスト/画像/動画/音声機能、タスクリソースはすべてプラットフォームが提供します。

### Zai に制作を開始または再開させるには？ {#start-or-resume-assistant}

プロジェクトの Zai 会話で目標を直接伝えるだけです。たとえば「制作を開始して」または「残りを続けて撮影して」のように指示します。Zai はまずプロジェクトの現在の進捗を確認し、中断したところから続行します。判断が必要な場合は、入力ボックスの上に質問カードまたは確認カードを表示します。

### Zai は確認なしにお金を使いますか？ {#assistant-spending}

承認した範囲を超えることはありません。

- 撮影開始前に、Zai が見積もりを提示します。「承認して開始」をクリックすると、その予算内の手順は中断なく自動的に実行されます。
- 撮影予算を超えた場合、または再作業予算が不足している場合は、確認カードが再度表示されます。
- ソーステキストの分析、プランの整理、脚本の初稿作成など、費用が発生しないアクションは直接完了し、後で報告されます。
- Zai が手動で編集したコンテンツを上書きしようとする場合も、まず同意を求めます。

### 一部だけ先に撮影できますか？ {#partial-production}

はい。Zai に「まず第1話を撮影して」または「最初の2つのセグメントだけ撮影して」と伝えます。見積もりと予算はそれらのセグメントのみを対象とし、以降の絵コンテと動画もその範囲内に収まります。終了後、Zai に残りを続行するよう伝えます。

### ワークスペースで直接編集した場合、Zai は認識しますか？ {#workbench-edits}

はい。アセットライブラリに新しい項目を追加すると、Zai はまずそれを読み取り、どのように使用するかを尋ねます。バージョンの切り替えや再合成などの操作は会話に記録が残り、Zai は次のターンの前にそれを確認します。Zai が編集したコンテンツを上書きしようとする場合、まず確認を求め、カードに「旧 → 新」の各変更を一覧表示します。

### Zai が開始しない、またはリクエストがタイムアウトする場合は？ {#assistant-startup-failure}

まずページを更新してください。接続が切れた場合、Zai は自動的に再接続し、現在のターンは中断されません。それでも動作しない場合は、時刻を記録し、「ヘルプ＆フィードバック」からオンラインサポートに連絡してください。

## モデルとプロバイダー {#providers-models-api}

### ZaiDrama はどのモデルをサポートしていますか？ 自分で選択できますか？ {#supported-providers}

プラットフォームは、タスク（テキストから画像、画像から動画、参照から動画、ナレーションなど）に基づいて、呼び出しごとにモデルを選択します。利用可能な範囲は製品ページに表示されます。「プロジェクト情報」のエピソードパラメータ（プロモード）、プロジェクト設定のナレーション音声、クリエイティブキャンバスの生成パネルで、プラットフォームが利用可能な候補から選択できます。Zai の会話モデルは選択できません。[モデルと機能](./models.md)をご参照ください。

### ZaiDrama で自分のモデルプロバイダーを使用できますか？ {#custom-provider-setup}

いいえ。ZaiDrama はすぐに使えるモデルを提供しており、独自のモデルプロバイダーの追加はサポートしていません。

- 自分のプログラムからプラットフォームのモデルを呼び出すには：開発者コンソールで API キーを作成し、base_url を `https://api.ourzai.com/v1` に設定します。[API クイックスタート](../api/quickstart.md)をご参照ください。
- ZaiDrama の「設定 → API トークン」オプションは、外部ツールが ZaiDrama 自体にアクセスするためのトークンを作成するもので、開発者コンソールの API キーとは異なります。

### 生成が失敗した場合はどうすればよいですか？ {#auth-rate-limit-timeout}

まず失敗理由を確認してください。会話内の送信カードとバッチページの両方に、どの項目がなぜ失敗したかが表示されます。上流サービスがレート制限または一時的に利用できない場合、プラットフォームは自動的に再試行します。再試行で解決しない場合は、影響を受けたセグメントのみを再撮影してください。バッチ全体を再送信しないでください。送信後にタイムアウトが発生した場合、上流タスクがすでに作成されている可能性があります。短時間に盲目的に再試行せず、しばらく待って結果を確認し、問題が続く場合はサポートに連絡してください。

## プロジェクトのワークフローと制作 {#project-workflow-and-tasks}

### ストーリーテリング、エピソード、広告モードを最初に選択する必要がありますか？ {#choose-mode-and-route}

いいえ。プロジェクトにはコンテンツモードがなく、作成後に固定される生成ルートもありません。Zai は素材に基づいて、各セグメントのタイプ（演技、ナレーション、ショーケースなど）と動画生成方法（絵コンテガイドまたは参照ガイド）を決定します。同じエピソード内で混在させることができます。[制作ワークフロー](./workflows.md)をご参照ください。

### どのソースファイル形式がサポートされていますか？ {#supported-source-formats}

- ファイル：`.txt`、`.md`、`.docx`、`.epub`、`.pdf`。各ファイルは 50MB 未満、1 回の添付につき最大 5 ファイル。
- 画像：PNG、JPG、WebP。各画像は 5MB 未満、1 回の添付につき最大 5 枚。
- ホームページまたはプロジェクト内の Zai 入力ボックスにファイルと画像を直接添付できます。プロジェクトの脚本ページで「ソースファイルをアップロード」を使用することもできます。
- 非常に長いテキストを貼り付けると、自動的に「貼り付けテキスト」カードに折りたたまれ、送信時にソーステキストとして保存されます。

スキャンされた PDF には抽出可能なテキストがないため、事前に OCR が必要です。古い `.doc` ファイルは、アップロード前に `.docx` に変換してください。

### 制作の進捗はどこで確認できますか？ {#production-progress}

- トップバー中央のステータスラベル（例：「制作中 · 絵コンテ 8/11」または「判断が必要です」）。
- ワークスペースのかんばんボードにある 5 段階の進捗、「判断が必要です」、「最新の出力」。
- バッチページでのバッチごとのプレビュー。各セグメントには、動画モデルに送信されたプロンプトと、失敗した場合の理由が表示されます。

### 制作が止まってしまうのはなぜですか？ {#stage-blocked}

一般的な理由：

- 確認待ちの手順がある（かんばんに「確認が必要な手順があります」と表示され、ダイアログボックスの上に確認カードが表示されます）。
- キャラクターに複数のルックがあるが、一部のセグメントでルックが選択されていない。
- ステージ内の一部のセグメントが失敗し、再試行するか修正するかの判断が必要。
- 現在の撮影範囲が完了している。続行するには Zai に伝える必要があります。

### 制作を一時停止、再開、キャンセルするには？ {#task-states}

会話で Zai に伝えるだけです。たとえば「一時停止して」「続行して」「この制作をキャンセルして」のように指示します。キャンセルして再開した後は、キャンセルまたは欠落した部分のみが再実行され、完了した結果は保持されて再利用されます。

### 1 つのセグメントだけを再撮影したい場合は？ {#reshoot-segment}

会話で、どのセグメントをどのように変更するかを指定します。たとえば「セグメント3で彼女をもっと冷たくして」のように伝えます。Zai は変更内容の旧 → 新の比較を表示します。確認後、そのセグメントの動画のみが再作成されます。再撮影には初期撮影予算とは別の再作業予算が使用されます。不足している場合は、Zai が再度確認を求めます。

### 満足のいくバージョンが再生成されて置き換えられるのを防ぐには？ {#pin-version}

そのアセットの「バージョン履歴」で「現在のバージョンをロック」をクリックします。ロック後、再生成された結果は履歴候補に入るのみで、現在のバージョンを自動的に置き換えることはありません。また、「このバージョンに切り替え」をクリックすれば、いつでも以前の結果に戻すことができます。

## ビジュアル、動画、音声 {#visuals-video-audio}

### キャラクターの一貫性を向上させるには？ {#character-consistency}

まずキャラクター参照シート（頭と肩のクローズアップ1枚と、正面、横、背面の全身図を含む1枚の画像）を確定してから、絵コンテと動画を生成します。グローバルアセットライブラリは検索とプロジェクト間の再利用をサポートしています。アセット定義が変更された場合、既存の絵コンテと動画は黙って上書きされず、現在のコンテンツより古いとマークされ、再撮影するかどうかはユーザーが決定します。

### 物語の中でキャラクターが衣装を変える場合は？ {#character-looks}

キャラクターに新しい**ルック**を追加します。アセットライブラリのキャラクター詳細で「ルックを追加」をクリックし、髪型、服装、アクセサリーを入力して参照シートを生成します（メインルックの参照シートが先に必要です）。その後、脚本で各セグメントにこのキャラクターが着る衣装を選択します。選択されていないセグメントは脚本ステップで停止します。Zai にルックを書いてもらい、セグメントのルック選択を入力してもらうこともできます。

### 隣接するセグメントの一貫性を高めるには？ {#shot-continuity}

動画を生成する前に、キャラクター、シーン、ルックをロックします。場所、時間、服装、キャラクターの説明を一貫させます。絵コンテガイドのセグメントは、前のセグメントの絵コンテ画像を参照して連続性を保ちます。

### 最初と最後のフレームはどのように機能しますか？ {#first-and-last-frame}

プロジェクトでは、絵コンテガイドのセグメントは絵コンテ画像を動画の最初のフレームとして使用します。最後のフレームは使用されません。最初と最後のフレームの両方を制御するには、[クリエイティブキャンバス](./canvas.md)で動画ノードの「最初/最後のフレーム」を有効にします（選択したモデルがサポートしているかどうかによります）。

### シーンデザイン画像に人物が写るのはなぜですか？ {#people-in-scene-images}

シーンデザイン画像は人物を除外するようにプロンプトが設定されていますが、画像モデルが完全に従わない場合があります。シーン画像を再生成するか、画像編集を使用して人物を削除できます。

### ZaiDrama はナレーションをサポートしていますか？ {#voice-over-support}

- **セリフ**は動画モデルが直接発話します。
- **ナレーション**の提供方法は、「プロジェクト情報」のエピソードパラメータで選択します：ポストプロダクション吹き替え（デフォルト、最終動画にはナレーション音声が含まれません）または TTS 吹き替え（プラットフォームが合成したナレーション）。吹き替えモデル、音声、速度は、プロジェクト設定の「ナレーション音声」で調整します。
- ナレーションセグメントのプレーヤーでは、「元の動画」と「TTS オーバーレイ」を切り替えられます。

### 字幕スタイルを調整できますか？ {#subtitle-style}

はい。「プロジェクト情報 → 字幕スタイル」で、フォントサイズ、縦位置、色、フォントを調整できます。プレビューには最終動画に焼き込まれる内容が正確に表示され、次の合成以降に反映されます。

## クリエイティブキャンバス {#creative-canvas}

### クリエイティブキャンバスとは何ですか？ プロジェクトとの違いは？ {#canvas-vs-project}

クリエイティブキャンバスは、テキスト、画像、動画、音声をノードとして配置し、それらに直接生成できる個人用の自由形式のキャンバスです。プロジェクトに紐づかず、脚本、バッチ、最終動画の納品はありません。複数話のドラマを完全に撮影する場合はプロジェクトを使用し、ビジュアルを自由に試したり、独立した動画セグメントを作成したりする場合はキャンバスを使用します。どちらもグローバルアセットライブラリを通じてアセットを共有します。[クリエイティブキャンバス](./canvas.md)をご参照ください。

### Zai はキャンバスで直接お金を使いますか？ {#canvas-approval}

デフォルトでは使いません。Zai が生成にお金を使おうとすると、推定コスト（米ドル）と残高を表示する承認バーが表示され、確認を求められます。承認モードを「直接生成」に変更するか、承認バーの「このターンの残りを自動確認」にチェックを入れると、そのターンの残りについて累積上限 $0.20 まで画像ごとの確認をスキップできます。ノードの削除やキャンバスのクリアなど、元に戻せないアクションには常に確認が必要です。

### キャンバスを共有またはバックアップできますか？ {#canvas-share-export}

- 「共有」は読み取り専用リンクを生成し、ログインしていなくても他の人が閲覧できます。いつでも取り消せます。
- キャンバスは zip としてエクスポートし、zip からインポートできます。
- 「バージョン履歴」では、スナップショットのプレビュー、名前付け、復元、新しいキャンバスとして保存ができます。

## コスト、データ、ダウンロード {#cost-data-export}

### 残高と支出はどこで確認できますか？ {#view-and-control-cost}

トップバーの残高バッジに現在の米ドル残高が表示されます。クリックすると使用詳細を確認できます。アカウントメニューの「請求と残高」では、利用可能残高、凍結額、残高詳細、購入履歴を確認でき、そこでチャージもできます。残高は小数点以下2桁で表示され（切り捨て）、各請求およびその他の詳細は小数点以下4桁で表示されます。毎日のログイン報酬と紹介報酬は「特典センター」にあります。

### 何をダウンロードできますか？ {#project-zip-vs-full-backup}

- **最終動画**：バッチページ → 「レビュー」ビュー → 「エピソード動画」 → そのエピソードの「ダウンロード」。
- **編集可能パッケージ**：動画セグメントプレーヤーの「編集可能パッケージをダウンロード」。動画、ナレーション音声、字幕（`.vtt` / `.srt`）、および他のソフトウェアでさらに編集するための説明ファイルを含む zip です。
- **ナレーション音声**：ナレーションのバージョン履歴にある「音声をダウンロード」。

プラットフォームはプロジェクト全体の ZIP エクスポートを提供していません。

### 編集可能パッケージにセグメントが欠けているのはなぜですか？ {#project-export-missing-clips}

編集可能パッケージには、正常に生成されたコンテンツのみが含まれます。欠けているセグメントについては、バッチページで失敗理由を確認し、再撮影または再生成してから再度ダウンロードしてください。

### モバイルアプリはありますか？ {#mobile-app-support}

ZaiDrama は Web アプリであり、現時点ではスタンドアロンのネイティブ iOS または Android アプリはありません。スマートフォンではブラウザからアクセスできますが、バッチのレビューやキャンバスの編集はデスクトップでの使用をおすすめします。

### 商用利用やその上での開発はできますか？ {#commercial-use}

ZaiDrama のソースコードは AGPL-3.0 で公開されています。[GitHub](https://github.com/z55183980-gif/zaidrama) のソースリポジトリをご参照ください。

## 品質とコストのベストプラクティス {#quality-and-cost-best-practices}

1. 規模を拡大する前に、まずいくつかのセグメントを撮影して、アートスタイル、キャラクター、ペースを検証します。
2. 絵コンテと動画を一括生成する前に、キャラクター参照シートとルックを確定します。
3. 隣接するセグメント間で、場所、時間、服装、キャラクターの説明を一貫させます。
4. 現在のセグメントが実際に必要とするアセットのみを参照します。参照画像が多すぎると制約が薄まります。
5. 1 つのセグメントに問題がある場合は、そのセグメントのみを再撮影します。満足のいくバージョンは速やかにロックします。
6. 「請求と残高」の残高と詳細に基づいて制作範囲を計画します。
