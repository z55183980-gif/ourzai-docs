# ZaiDramaのモデルと機能 {#providers}

このページでは、ZaiDramaでのモデルの選択方法、機能の理解、生成問題の解決方法について説明します。プラットフォームのモデルを自分のアプリケーションから直接呼び出す方法については、[APIクイックスタート](../api/quickstart.md)を参照してください。

ZaiDramaで制作するために、サードパーティのAPIキーを用意する必要はありません。ZaiDramaはすべての呼び出しで**目的別に**モデルを選択し、ユーザーはプラットフォームが提示する候補の中から数か所で選択するだけです。

## 1. 目的別のモデル選択 {#model-usages}

すべてのモデル呼び出しは、固定された目的に属します。

| カテゴリ | 目的 | 機能 |
| --- | --- | --- |
| テキスト | 単純なタスク | 元テキストの要約、スタイル画像の分析、一貫性チェック |
| テキスト | 複雑なタスク | 脚本、バッチ計画、キャンバスでの執筆 |
| テキスト | キャンバスアシスタント | クリエイティブキャンバスでユーザーに代わってZaiが行動 |
| テキスト | キャンバスの視覚・音声理解 | ノード内の画像、動画、音声をキャンバスのZaiが閲覧 |
| テキスト | ウェブ検索 | リアルタイム情報が必要な場合にキャンバスのZaiがウェブを検索 |
| 画像 | テキストから画像生成 | キャラクター画像、シーン画像、絵コンテ画像など、テキストのみからの画像生成 |
| 画像 | 画像から画像生成 | 参照画像を使用した画像生成と画像編集 |
| 動画 | 画像から動画生成 | 絵コンテの最初のフレームとグリッドレイアウトによる動画生成 |
| 動画 | 参照から動画生成 | キャラクター、シーン、小道具、または商品の参照画像から直接動画を生成 |
| 音声 | ナレーション | ナレーションの吹き替えとキャラクターボイスのプレビュー |

デフォルトの選択を使用する場合、プラットフォームは対応する目的に現在利用可能なモデルを選択します。

## 2. モデルを選択できる場所 {#user-model-selection}

| 場所 | 選択できる内容 |
| --- | --- |
| プロジェクト情報 → エピソードパラメータ → 自動モード | モデル選択なし。「画質」（高速 / 標準 / 高品質）とアスペクト比のみ選択。プラットフォームが品質レベルに応じてモデルを選択 |
| プロジェクト情報 → エピソードパラメータ → プロモード | 画像から動画、参照から動画、テキストから画像、画像から画像についてモデルと解像度を個別に選択。デフォルトは「グローバルルーティングに従う」 |
| プロジェクト設定 → ナレーション吹き替え | デフォルトのナレーションモデル、ナレーション音声、話速 |
| クリエイティブキャンバス → ノード生成パネル | この生成に使用されるモデル |

- ドロップダウンメニューには、その目的に現在利用可能なモデルが表示されます。
- プロジェクトで指定されたモデルが一時的に利用できない場合、インターフェースに「プロジェクトで指定されたモデルは現在利用できません。」と表示されます。「グローバルルーティングに従う」に切り替えることができます。
- Zaiの会話モデルとその他のテキスト目的はプラットフォームが設定するため、ユーザーは選択できません。
- 個人の「設定」ページにはモデルオプションはありません。

初めての作品制作では、範囲を広げる前に少数のクリップでスタイルと結果を検証することをお勧めします。

## 3. 機能の境界 {#capability-boundaries}

プラットフォームは、ベンダー全体から推測するのではなく、特定のモデルごとに機能を宣言します。以下は機能カテゴリです。特定のモデルがどれをサポートしているかは、生成パネルとドロップダウンで実際に利用可能なオプションによって異なります。

- **テキスト**：構造化出力、画像理解（画像入力）
- **画像**：テキストから画像生成、画像から画像生成（参照画像による生成と編集）、サポートされる解像度とアスペクト比
- **動画**：画像から動画生成（最初のフレーム駆動、一部のモデルはエンドフレームをサポート）、参照から動画生成（モデルによって参照画像の数と種類が異なる）、参照音声、サポートされる長さ、解像度、アスペクト比
- **動画の音声トラック**：音声トラックを生成するかどうかを選択できるモデル、常に音声を生成するモデル、常に無音のモデルがあります
- **音声**：TTSと選択可能な音声。話速はプロジェクト設定またはキャンバスの音声ノードで調整します

モデルの宣言された機能を超えるリクエスト（例：エンドフレームをサポートしていないモデルにエンドフレームを渡す場合）は、送信前に明示的に拒否され、選択していないモデルに黙って置き換えられることはありません。

## 4. 料金とクレジット {#credits-and-usage}

ユーザーは、アカウントメニューの「請求と残高」で利用可能な残高と残高明細を参照してください。プラットフォームは各生成の目的、モデル、ステータス、コスト（米ドル）を記録します。各生成は「レート×使用量」として課金され、$0.0001単位で、最低$0.0001です。課金結果は残高明細に反映されます。

残高不足や異常な課金が発生した場合は、プロジェクト名と発生時刻を控え、「ヘルプとフィードバック」からオンラインサポートにお問い合わせください。生成を繰り返しクリックしたり、クレジットチェックを回避しようとしたりしないでください。

## 5. トラブルシューティング {#troubleshooting}

### ユーザー側 {#user-troubleshooting}

- **ドロップダウンにモデルがない**：その目的には提供されていないか、一時的に利用できません
- **プロジェクトで指定されたモデルが利用できない**：「グローバルルーティングに従う」に戻すか、別の候補を選択してください
- **生成に失敗した**：まず会話ページまたはバッチページに表示される失敗理由を読み、影響を受けたクリップのみを再試行してください
- **待ち時間が長すぎる**：タスクはプラットフォームによって一元的にスケジュールされます。再送信しないでください
- **残高不足**：「請求と残高」で残高と明細を確認してください
