# クリエイティブキャンバス {#canvas}

クリエイティブキャンバスは、アイデア、参考資料、生成結果を自由に配置できる無限キャンバスです。ノード上で直接、画像、動画、テキスト、音声を生成したり、ある画像を次のノードに渡してさらに加工したり、キャンバス上のZaiに画像の編集や動画作成を依頼したりできます。スタイルの試行、コンセプトアートの作成、単一ショットの磨き上げ、完全な脚本を必要としない短い動画の作成に適しています。

## 1. キャンバスとプロジェクトの関係 {#canvas-and-projects}

- キャンバスは個人に属するもので、特定のプロジェクトには紐付きません。プロジェクトがキャンバスの内容を読み取ることもありません。
- キャンバスは第二の制作パイプラインではありません。脚本、バッチ処理、最終納品の機能はなく、生成結果が自動的にプロジェクトに入ることもありません。
- 両者は**グローバルアセットライブラリ**を通じて連携します。キャンバス上の画像は「アセットライブラリに保存」で送信でき、プロジェクトではアセットライブラリページの「ライブラリから」で再利用できます。また、キャンバスのサイドバーにある「アセット」タブから、アセットライブラリのコンテンツをキャンバスに配置することもできます。

完全なストーリーを複数話のショートドラマとして制作する必要がある場合はプロジェクトを使用し、まずビジュアルを自由に試したい場合や、単独の動画を数本だけ作成したい場合はキャンバスを使用します。

## 2. キャンバスの作成と管理 {#manage-canvases}

サイドバーの「クリエイティブキャンバス」をクリックすると、キャンバス一覧が開きます。キャンバスがまったくない状態で初めてアクセスした場合は、空白のキャンバスが直接開きます。

一覧は「今日 / 過去7日間 / それ以前」でグループ化され、各カードにはキャンバスの内容が表示されます。一覧では以下が可能です。

- 上部バーからキャンバス名や内容を検索
- 「新規キャンバス」の作成、または既存キャンバスの「複製」
- キャンバスをZIP形式で「インポート」、またはZIP形式で「エクスポート」（インポートしたパッケージが認識できない場合は、メディアのみがインポートされます）
- 複数のキャンバスを「選択」して一括でエクスポートまたは削除
- キャンバスの名前変更と削除

キャンバスには内容に基づいて自動的に名前が付けられます。最初にテキストがキャンバスに配置されると最初のノードにちなんで名前が付けられ、Zaiがキャンバス上で何かを生成した後は、そのターンのリクエストにちなんで名前が付けられます。自分で変更した名前が上書きされることはありません。何もせずに閉じた空白のキャンバスは自動的に破棄され、一覧には残りません。

各キャンバスは新しいブラウザタブで開きます。キャンバスは自動保存され、上部バーに「保存済み / 保存中… / 未保存」と表示されます。同じキャンバスを2つのウィンドウで同時に編集して編集が競合した場合は、「別ウィンドウでの変更と競合しています」という警告が表示されます。

## 3. ノードと接続 {#nodes}

ツールバーには以下が用意されています。

- **選択 / 手のひら**：ノードの選択またはキャンバスのパン
- **ノードを追加**：テキスト、画像、動画、音声。複数のノードをグループにまとめることもできます
- **ファイルをアップロード**：PNG、JPG、WEBP、MP4、WEBM、MP3、WAV。画像は最大20MB、動画は最大200MB、音声は最大30MB
- **既存のアセットを使用**：過去にアップロードまたは生成した素材から選択
- **プリセット**：例えば「脚本ライター」や「キャラクターターンアラウンド」など、よく使うノード一式を一度に配置できます
- **キャンバス設定**：デフォルトのアスペクト比、デフォルトの画像解像度、背景スタイル、「キャンバスをクリア」

ノード間の接続は入力関係を表します。画像ノードを動画ノードに接続すると、その画像が動画の最初のフレームまたは参照になります。

サイドバーには「キャンバス」、「アセット」、「プロンプト」の3つのタブがあります。「プロンプト」には、公開コレクションと自分専用の「マイ」プロンプトライブラリが含まれます。

## 4. ノードでの生成 {#generate}

ノードを選択すると、生成パネルが開きます。

| 生成 | 設定 |
| --- | --- |
| 画像を生成 | モデル、解像度、画像数、アスペクト比、スタイル。アスペクト比を「自動」に設定すると、最初の参照画像に最も近い比率が使用されます |
| 動画を生成 | 1枚の画像を最初のフレームとして接続します（動画は通常その形状に従います）。2枚以上接続すると、すべてが参照として取り込まれ、`@` を使用して各画像の役割を指定し、選択したアスペクト比で動画が生成されます。「最初と最後のフレーム」をオンにすると、最初の2枚の画像が開始フレームと終了フレームになります。解像度、長さ、音声を生成するかどうか |
| テキストを書く | 何を書くか |
| 音声 | 音声、速度 |

生成が完了すると、ノード上のクイックアクションから「動画を作成」、「画像を作成」、「ナレーションを追加」、「次のショット」を続けて実行できます。

画像ノードには、プロンプトとして説明、切り抜き、分割、アップスケール、インペイント、新しいアングル、動画の最初 / 現在 / 最後のフレームの取得、アセットライブラリへの保存などのツールも用意されています。このうち、切り抜き、分割、アップスケールはブラウザ内で実行され、無料です。

選択可能な生成モデルは、プラットフォームが各用途向けに公開している候補から提供されます。詳細は[モデルと機能](./models.md)を参照してください。

## 5. キャンバス上のZai {#canvas-zai}

キャンバスの右下隅にあるZaiウィンドウは、ドラッグして移動したりサイズを変更したりできます。ダブルクリックすると右下隅に戻ります。Zaiはこのキャンバスを確認でき、キャンバスを編集することもできます。

- **範囲**：ノードが選択されている場合は、「選択中のN個」のノードのみを操作します。それ以外の場合は「キャンバス全体」を操作します
- **素材の閲覧**：ノード内の画像、動画、音声を閲覧できます
- **ウェブ検索**：必要に応じてウェブを検索し、取得した内容は参考資料としてのみ使用されます
- **メモ**：Zaiはパネル上部のメモを毎ターン読み取ります。あなたもZaiもメモを編集できます。アスペクト比、スタイル、解像度などのキャンバスのデフォルト設定は新しいキャンバスに自動的に引き継がれるため、メモに書く必要はありません
- **このターンを元に戻す**：このターンでZaiがキャンバスに加えたすべての変更をワンクリックで元に戻します

キャンバス上のZaiは、ショートドラマの制作を前提としていません。物語を書く、ポスターを作る、商品画像を作成するなど、すべてに対応します。使用するチャットモデルはプラットフォームによって設定されます。

### 5.1 生成前の確認 {#approval}

生成に費用がかかる場合、デフォルトではZaiが最初に承認バーを表示し、推定コスト（米ドル）と残高を示します。「生成」をクリックした後にのみ実行されます。「キャンバスで表示」をクリックすると、変更しようとしているノードを先に確認できます。

- Zaiパネルの承認設定で「直接生成」に切り替えると、以降は毎回の確認が不要になります。
- 承認バーで「このターンの残りを自動確認」をチェックすると、累計上限0.20ドル以内であれば、このターンの残りの生成はカードが1つずつ表示されなくなります。上限を超えることになる1回の生成は通常どおり確認されます。
- ノードの削除やキャンバスのクリアなど、元に戻せない操作には常に確認が必要です。

## 6. 履歴 {#history}

上部バーの「履歴」では、キャンバスのスナップショットをプレビュー、名前付け、復元できます。

- 編集中、プラットフォームが定期的にバージョンを自動保存します。コンテンツが削除される前、バージョンが復元される前、Zaiがキャンバスを変更する前にも1つ保存されます
- 「バージョンを保存」で作成して名前を付けたバージョンは、自動的にはクリーンアップされません
- 「このバージョンを復元」または「新しいキャンバスとして保存」できます

## 7. 共有 {#share}

上部バーの「共有」では、**読み取り専用リンク**を生成できます。リンクを知っている人は誰でも、サインインせずにこのキャンバスを閲覧できますが、編集はできません。いつでも「リンクを取り消す」ことができ、取り消し後はリンクがすぐに無効になります。
