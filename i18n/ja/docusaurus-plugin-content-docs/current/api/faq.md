# API に関するよくある質問 {#faq}

## ZAI の API とは何ですか？ {#what-is-it}

ZAI 開発者 API は、OpenAI の API 形式に準拠したモデルゲートウェイです。1 つの API キーと 1 つの base_url（`https://api.ourzai.com/v1`）で、GPT、Claude、Grok などの複数ベンダーのチャット、画像、音声、動画モデルを呼び出せます。既存の OpenAI SDK や HTTP のコードは、base_url とキーを変えるだけで使えます。[APIクイックスタート](./quickstart.md)を参照してください。

## 香港、台湾、その他の地域で使えますか？ {#regions}

はい。API は各地の開発者向けに提供しています。香港、台湾、東南アジアなどでも、そのまま登録、チャージ、呼び出しができます。リクエストはすべて `https://api.ourzai.com` に送られます。[利用規約](https://ourzai.com/legal/terms.html)と所在地の法律を守ってご利用ください。

## 支払い方法は？ {#payment}

[開発者コンソール](https://ourzai.com/console)の「Top up」ページでチャージパックを購入します。支払いは Stripe が処理し、利用できる支払い方法は決済ページに表示されます。チャージ分は米ドル残高として入金され、有効期限はありません。[クレジット](../platform/account.md#credits)を参照してください。

## 料金はどのように請求されますか？月額料金はありますか？ {#billing}

月額料金もサブスクリプションもありません。呼び出しごとに、実際の使用量に応じて米ドル残高から差し引かれます。課金単位はモデルの種類によって異なり（100 万トークンあたり、または課金単位あたり）、動画タスクは動画の生成に成功したときに 1 回だけ課金されます。[課金と利用状況](./errors.md#billing)を参照してください。

## 公式 API と比べて料金はどうですか？ {#price}

コンソールの **Pricing** ページに、各モデルの米ドル単価と、ベンダーの公開定価からの割引率が表示されます。料金は変わることがあり、このページには常に最新の料金が表示されます。

## OpenAI や Anthropic の公式 API を直接使う場合と何が違いますか？ {#vs-official}

- 1 つのキーで複数ベンダーのモデルを呼び出せ、すべての利用状況と請求を 1 つのコンソールで確認できます。
- エンドポイントは OpenAI 形式に統一されているため、Claude のチャットモデルも `/v1/chat/completions` で呼び出せます。ネイティブの `messages` エンドポイントを提供する Claude モデルは、Anthropic SDK から直接使うこともできます。[インターフェースと機能](./endpoints.md)を参照してください。
- モデル ID はこのプラットフォーム独自のもので、同じベンダーでもモデルによって提供するエンドポイントが同じとは限りません。[モデル一覧と接続方法](./models.md)を参照してください。
- 上流ベンダーで障害やレート制限が起きると、リクエストが 502/503 を返すことがあります。時間をおいてバックオフしながら再試行してください。[5xx サービス一時利用不可](./errors.md#status-5xx)を参照してください。

## Cursor、Cline、Claude Code、Codex で使えますか？ {#tools}

はい。各ツールで base_url、キー、モデルを入力する場所は、[コーディングツールで使う](./tools/tools.md)を参照してください。

## 問題が起きたときの連絡先は？ {#support}

support@ourzai.com に、アカウントのメールアドレス、エラーが起きた時刻、レスポンスのエラーメッセージを添えてメールしてください。API キーは含めないでください。その他の連絡方法は[お問い合わせとサポート](../platform/account.md#support)を参照してください。
