# キー管理ツール {#key-tool}

キー管理ツールは ZAI が提供するデスクトップアプリです。API キーを 1 か所でまとめて管理し、Claude と Codex から ZAI API を使うための設定を行うので、設定ファイルを手作業で編集する必要がありません。キーの作成は、これまでどおり[開発者コンソール](https://ourzai.com/console)の **API keys** ページで行います。

## ダウンロード {#download}

macOS 12+ · Intel / Apple Silicon

[GitHub ソースコード](https://github.com/z55183980-gif/ourzai-keytool)

</KeyToolDownload>

インストール後、ログインしてキーを取り込むか手動で追加し、クライアントとモデルを選んで起動します。Claude や Codex は別途インストールが必要です。
