# プラットフォーム概要 {#overview}

ZAIは、現在3つのプロダクトカテゴリを提供するAIプラットフォームです。

- **AIコンパニオン（Meet Zai）**: チャットできるAIパートナーをお探しの方に。zai.ggで気軽にチャットや音声通話を楽しみ、アバターや関係性のスタイルを選択し、長期的な記憶を管理できます。
- **APIアクセス**: 開発者向け。1つのベースURLと1つのAPIキーで、チャット、画像、動画、音声のすべてを単一のエントリーポイントから利用でき、各呼び出しは利用量に応じて残高から課金されます。キー、利用状況、チャージは開発者コンソールで管理できます。
- **クリエイション・ワークスペース（ZaiDrama）**: クリエイター向け。アイデア、小説、脚本、製品紹介を短編ドラマ、広告、解説動画に変換できます。脚本、キャラクター、シーン、絵コンテ、最終出力のすべてを1つのプロジェクト内で行えます。

3つのプロダクトはすべて同じプラットフォームアカウントを共有します。APIとZaiDramaは米ドル残高を共有し、Meet Zaiの無料枠、メンバーシップ、音声利用枠についてはコンパニオンプランで詳しく説明しています。

## すべてのプロダクトで1つのアカウント {#one-account}

プラットフォームアカウントはメールアドレスで登録します。一度登録すれば、Meet Zai、開発者コンソール、ZaiDramaにログインできます。すべてのプロダクトで同じアカウントログインを使用し、有効なセッションが既にあれば、そのまま入ることができます。セッションが期限切れになった場合や確認が必要な場合は、画面の指示に従って再度ログインしてください。公式ホームページの「クリエイション・ワークスペース」リンクからZaiDramaにアクセスできます。

登録、ログイン、パスワードの復元、アカウントのセキュリティについては、[アカウント、残高、サポート](./account.md)をご覧ください。

## プラットフォーム残高とコンパニオン特典 {#credits}

APIとZaiDramaのプラットフォーム残高は米ドル建てで管理・課金されます。

- ZaiDramaで画像、動画、ナレーションを生成すると残高から差し引かれます。
- APIを介してモデルを呼び出すと、呼び出しごとの利用量に基づいて残高から差し引かれます。
- 公式ウェブサイトでプラットフォームアシスタントとチャットしても、プラットフォーム残高から差し引かれることはありません。

残高は、開発者コンソールの「チャージ（Top up）」ページ、またはZaiDramaの「請求と残高（Billing & Balance）」ページでチャージできます。どちらのチャージ場所でも同じ残高に加算され、チャージした残高に有効期限はありません。モデルごとの米ドル料金は、コンソールの「料金（Pricing）」で確認するか、ホームページのプラットフォームアシスタントに直接尋ねることができます。

Meet Zaiのメンバーシップ有効期間、音声返信時間、通話時間、追加パックについては、[コンパニオンプランと利用状況](../zai/plans-and-usage.md)で説明しています。プラットフォーム残高へのチャージはZai Plusの購入とは異なり、残高は音声利用枠の残量を示すものではありません。

## ホームページのプラットフォームアシスタント {#platform-assistant}

公式ホームページのZaiはプラットフォームアシスタントであり、人間のカスタマーサポートではなくAIです。以下のことができます。

- プラットフォームとそのプロダクトを紹介し、目的の場所を見つけるお手伝いをします。
- このサイトのドキュメントに基づいて、利用方法や連携に関する質問に回答し、ソースへのリンクを提示します。
- 現在利用可能なモデルとその公開米ドル料金を調べます。

アカウントの確認、残高や利用枠、注文の確認、またはお客様に代わっての操作はできません。人間によるサポートが必要な場合は、[お問い合わせとサポート](./account.md#support)をご覧ください。
