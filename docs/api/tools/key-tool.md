# 密钥管理工具 {#key-tool}

密钥管理工具是 ZAI 提供的桌面应用，用来集中管理你的 API 密钥，并为 Claude 与 Codex 配置 ZAI API 接入，不用手动编辑配置文件。密钥仍然在[开发者控制台](https://ourzai.com/console)「API 密钥」里新建。

## 下载 {#download}

[前往下载页](https://ourzai.com/tools/key-manager)选择 Windows 或 macOS 版本。

安装后，登录导入或手动添加密钥，选择客户端与模型即可启动。Claude 与 Codex 需单独安装。

## 手动配置 {#manual}

不使用密钥管理工具时，按各工具的教程配置：

- [Claude Code](./claude-code.md)
- [Claude 桌面版](./claude-desktop.md)
- [Codex CLI](./codex-cli.md)
- [Codex 桌面版](./codex-app.md)
