# 账号、余额与支持 {#account}

## 注册账号 {#register}

各产品都有注册入口，从任何一处注册得到的都是同一个 ZAI 账号，注册一次即可登录全部产品：

| 从哪里注册 | 入口 | 注册后 |
| --- | --- | --- |
| 官网 | 右上角「注册」，或登录窗口里的「还没有账号？注册」 | 登录成功后留在当前页面 |
| 开发者控制台 | 登录页底部的「去注册」 | 自动登录并进入控制台 |
| 遇见 Zai | [zai.gg](https://zai.gg) 登录页的注册入口 | 按页面提示进入陪伴产品 |
| ZaiDrama | 登录弹窗切换到「创建你的 ZAI 账号」，可填写邀请码 | 直接进入 ZaiDrama |

使用邮箱注册时：

- 需要填写邮箱收到的 6 位验证码（10 分钟内有效，60 秒后可重新发送）；
- 密码至少 6 位，需同时包含字母和数字；
- 同一个邮箱只能注册一次，已注册会提示「这个邮箱已经注册过了」，直接去登录即可。

如果注册前在官网首页和 Zai 聊过，这段对话会跟着进入新账号。

## 登录账号 {#sign-in}

- 用注册时的邮箱和密码登录。
- 官网、遇见 Zai 与 ZaiDrama 使用统一账号登录；已有有效登录状态时可直接进入，状态过期或需要验证时按页面提示重新登录。
- 登录页提供 Google 登录时，也可以选择「使用 Google 账号继续」；首次使用会按页面流程建立账号。
- 已在官网登录时，点首页的「创作工作台」会免密进入 ZaiDrama。
- 登录状态会自动续期；同一个账号同时登录的设备过多时，最早的会话会被挤下线。

## 忘记密码 {#reset-password}

在登录窗口点「忘记密码？」，输入注册邮箱，收到验证码后设置新密码。为了不暴露某个邮箱是否注册过，输入未注册的邮箱时页面同样会提示已发送。

## 账号安全 {#account-security}

在 ZaiDrama 的「个人中心」可以：

- 更换绑定邮箱（更换后用新邮箱登录各产品）；
- 修改密码；
- 查看「登录设备」，把不认识的设备逐个退出；
- 注销账号：输入完整邮箱和密码，阅读清除范围并再次确认。提交后会退出登录；资料清理可能需要时间，以页面显示的处理结果为准。注销不可撤销。

不要把密码、验证码或 API 密钥发给任何人，包括自称客服的人。

## 余额 {#credits}

- **一份余额**：余额以美元计。开发者控制台右上角显示的余额和 ZaiDrama 里的余额是同一个账户。ZaiDrama 生成图片、视频、配音，以及通过 API 调用模型，都从这里扣费；与官网平台助手对话不扣平台余额。
- **充值**：在开发者控制台的「充值」页或 ZaiDrama 的「账单与余额」页购买充值包。每个充值包标明到账金额（美元，含赠送部分）；以人民币标价的充值包按人民币付款，到账同样是美元余额。付款由 Stripe 处理，支持银行卡、支付宝和微信支付，平台不保存银行卡信息；支付宝和微信到账可能稍有延迟，付款确认后自动入账。
- **不过期**：充值到账的余额不会过期。
- **单价**：各模型的美元单价（每百万 Token 或每个计费单位）在控制台「模型定价」查看。ZaiDrama 的每次生成按「费率 × 用量」扣费，精确到 $0.0001，最低 $0.0001；开拍确认卡和审批条会先给出报价。
- **显示**：余额类数字（右上角余额、余额卡片、累计充值 / 消费）显示 2 位小数并向下截断，例如 `$1,234.56`，悬停可看 4 位精确值；每笔扣费、流水、报价等明细显示 4 位小数，例如 `$0.0123`。
- **记录**：控制台「充值」页的「账单」标签和 ZaiDrama「账单与余额」页可以查看充值记录；API 消耗在控制台「使用记录」查看，ZaiDrama 的扣费明细在「账单与余额」查看。

### 奖励 {#rewards}

ZaiDrama 的「福利中心」提供：

- **每日登录奖励**：活动开放且满足领取条件时，在 ZaiDrama 登录可自动领取；页面提供领取按钮时，也可按提示操作。金额、次数和累计上限以当前活动规则为准；
- **推荐奖励**：通过邀请链接或邀请码邀请新用户，按活动规则获得余额奖励。

奖励金额进入同一个余额。具体数额以福利中心页面为准。

## 遇见 Zai 的会员 {#companion-plans}

遇见 Zai 使用同一个平台账号，但免费版、Zai Plus、语音回复与通话时长、加量包在陪伴产品的会员页面管理。平台余额充值不等于购买会员，也不会把余额数字变成语音分钟数。

查看当前权益、恢复日期、购买与到期规则，见[会员与用量](../zai/plans-and-usage.md)。聊天、形象与记忆的操作从[遇见 Zai 快速开始](../zai/getting-started.md)进入。

## 退款 {#refunds}

退款规则见[服务条款](https://ourzai.com/legal/terms.html)第 6 节「订阅、付款与退款」，价格、退款等具体规则以购买页面展示为准。需要申请退款时，写信到 support@ourzai.com，写明注册邮箱和订单信息。

## 联系与支持 {#support}

| 渠道 | 适合 | 谁能用 |
| --- | --- | --- |
| 官网首页的 Zai | 了解平台、找文档、查可用模型和公开单价 | 所有人，无需注册 |
| 开发者控制台「新对话」 | 登录后直接问 Zai 接口怎么调、模型怎么选 | 已登录用户 |
| ZaiDrama「帮助与反馈」 | 创作过程中的问题，人工在线客服，可以发截图 | 已登录的 ZaiDrama 用户 |
| [官网联系我们](https://ourzai.com/contact) | 联系在线客服、查看其他联系渠道 | 所有人 |
| support@ourzai.com | 账号问题、退款申请、商务合作 | 所有人 |

官网首页的 Zai 暂时连不上时，会出现「转人工客服」按钮，之前的对话会一起转给客服。
