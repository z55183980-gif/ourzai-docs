# 记忆与数据管理 {#memory-and-data}

Zai 会在对话后整理长期记忆，帮助延续之后的交流。记忆不等于逐字保存所有聊天，也不保证每句话立即成为一条可见记忆。

## 查看和管理记忆 {#manage-memory}

1. 打开「设置 → 隐私与数据」。
2. 点击「查看和管理记忆」，进入记忆库。
3. 查看已保存的内容；发现不准确的记忆时，可以修正对应条目，不想保留的条目可以删除。
4. 操作后检查页面结果；如果提示失败，重新加载后确认当前内容再重试。

聊天记录与长期记忆分别管理。需要查看或删除聊天消息时，在聊天窗口操作。

## 暂停新增记忆 {#pause-memory}

在「设置 → 隐私与数据」打开「暂停记忆」。开启后，新聊的内容不会整理进长期记忆，已经记住的内容仍会照常使用。

关闭该开关后，可以继续整理新的记忆。暂停记忆不会清除已有记忆，也不是删除聊天记录的操作。

## 导出数据与导入记忆 {#export-and-import}

- **导出数据**：在「隐私与数据 → 数据管理」中点击「导出数据」旁的「下载」，保存包含聊天、记忆、日记等内容的导出文件。
- **导入记忆**：在同一页面选择「导入记忆」，按页面提示选择导出文件。导入会添加记忆并保留现有记忆，**不会恢复聊天和日记**。

导出文件包含你的个人对话资料，请保存在自己可控制的位置。导入、导出的成功或失败以页面结果为准。

导出中的语音记录保留文字，不包含语音音频。聊天中交付、保存在客户端的文档正文不属于服务端导出范围；需要保留时，请另行保存。导出不是整套应用状态的完整备份。

## 重新开始 {#start-over}

「隐私与数据」中的「重新开始」会清除聊天、记忆、便签和日记。账号、会员、形象、音色和关系设置保留。

清除后无法恢复。需要保留资料时，先导出数据；确认清除范围后再点击「确认清除」。导入记忆不能把整个聊天历史恢复回来。

账号注销与重新开始是不同操作。账号安全、条款和支持渠道见[账号、余额与支持](../platform/account.md)。
