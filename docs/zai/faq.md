# 遇见 Zai 常见问题 {#faq}

## 从哪里进入？需要 API 密钥吗？ {#entry}

打开 [zai.gg](https://zai.gg) 即可。使用已有 ZAI 账号登录，不需要自己创建或填写 API 密钥。初次使用见[快速开始](./getting-started.md)。

## 有平台账号，为什么还要登录？ {#sign-in}

同一个账号可以用于多个产品，但跨产品的登录状态可能不同。用原邮箱登录即可，不必重复注册。忘记密码时使用登录页的找回入口；详见[账号帮助](../platform/account.md#reset-password)。

## 为什么听不到声音，或者无法使用麦克风？ {#audio}

检查设备音量、浏览器音频和麦克风权限、聊天的语音模式，以及通话中的静音与声音开关。语音回复和语音通话分别有额度；排查步骤见[聊天与语音](./chat-and-voice.md#troubleshooting)。

## 平台有余额，为什么还提示语音额度用完？ {#allowance}

平台美元余额与遇见 Zai 的语音权益分别管理。到会员查看对应的语音回复或通话剩余时长、恢复日期与加量包；详见[会员与用量](./plans-and-usage.md)。

## Zai 记错了，或者没记住，怎么办？ {#memory}

记忆会在对话后整理，不是每句话都会立即成为长期记忆。先检查「暂停记忆」是否开启；在记忆库查看已保存内容，并修正或删除不准确的条目。具体操作见[记忆与数据管理](./memory-and-data.md)。

## 换形象或名字会清空记忆吗？ {#appearance}

不会。更换形象和名字会保留记忆。清理过往内容需要使用记忆管理或「重新开始」；后者会清除聊天、记忆、便签和日记，操作前请阅读[清除范围](./memory-and-data.md#start-over)。

## 导入记忆可以恢复全部聊天吗？ {#import}

不能。导入会添加记忆并保留已有记忆，不恢复聊天和日记。导出数据与导入记忆的范围见[数据管理](./memory-and-data.md#export-and-import)。

## 遇到问题找谁？ {#support}

在遇见 Zai 的产品菜单中选择「在线客服」可以直接求助。

联系 support@ourzai.com，写明发生在哪个产品、注册邮箱、发生时间和页面错误提示；付款问题附上订单信息。不要发送密码、验证码或 API 密钥。更多渠道见[联系与支持](../platform/account.md#support)。
