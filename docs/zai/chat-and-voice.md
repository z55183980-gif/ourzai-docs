# 聊天与语音 {#chat-and-voice}

在 [遇见 Zai](https://zai.gg) 中，可以打字聊天、发送语音，也可以直接和 Zai 通话。

## 文字聊天 {#text-chat}

在聊天输入框输入内容并发送。Zai 回复时可以继续阅读聊天记录；如果当前回复不再需要，可使用界面上的停止按钮结束当前任务。

连接中断时，先查看页面提示，再重试发送。若问题持续，记录发生时间和错误提示，通过[联系与支持](../platform/account.md#support)反馈。

## 三种语音用法 {#voice-options}

| 功能 | 你会怎么用 | 与其他功能的区别 |
| --- | --- | --- |
| 语音消息 | 使用输入区的麦克风录音，按提示发送 | 用说话代替打字发送一条消息 |
| 语音回复 | 在聊天中切换到语音模式，听 Zai 的回复 | Zai 把回复说给你听，使用语音回复时长 |
| 语音通话 | 点击「语音通话」，允许使用麦克风后实时交谈 | 独立的通话过程，使用语音通话时长 |

语音回复和语音通话分别显示额度。录一条语音消息不等于开启实时通话。

## 调整语音回复 {#voice-replies}

1. 在聊天界面切换到语音模式。
2. 在语音模式选项中设置是否自动播放。
3. 到「设置 → 声音」选择音色、调整音量，并查看本期剩余语音回复时长。

需要安静阅读时，切回文字模式即可。语音回复时长耗尽时，界面会提示改用文字回复；恢复时间和可用加量包见[会员与用量](./plans-and-usage.md)。

## 进行语音通话 {#voice-call}

1. 点击聊天界面的「语音通话」。
2. 浏览器询问麦克风权限时选择允许，并确认设备的麦克风可用。
3. 通话中可以静音或取消静音、开关 Zai 的声音。桌面端收起通话窗口后，点击最小化通话条恢复；不要点击人物下方的通话按钮来恢复，它在通话中会挂断。
4. 结束交流时点击「结束」或「挂断」。移动端直接使用通话界面上的控制按钮，不套用桌面窗口的收起操作。

如果页面提示通话额度已用完，在会员中查看恢复时间与加量包。如果提示暂时无法通话，稍后重试。

## 没有声音或无法录音 {#troubleshooting}

- **无法录音**：检查浏览器的网站麦克风权限，以及系统中是否选中了正确的输入设备。
- **听不到回复**：检查设备和页面音量、标签页是否静音，以及语音回复是否开启。浏览器阻止自动播放时，手动点击播放。
- **通话听不到 Zai**：检查通话界面的声音开关；麦克风静音控制的是你说话的声音。
- **有额度但仍失败**：记录页面错误提示，刷新后重试；持续失败时联系支持。

音色的选择与更换见[形象、声音与相处关系](./appearance-and-relationship.md#voice)。
