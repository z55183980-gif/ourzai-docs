# 遇见 Zai：快速开始 {#getting-started}

遇见 Zai 是 ZAI 的 AI 陪伴产品。你可以和 Zai 聊日常、分享心事，选择喜欢的形象与相处关系，也可以用语音回复和通话交流。

**[打开遇见 Zai](https://zai.gg)**

## 开始第一次聊天 {#first-chat}

1. 打开 [zai.gg](https://zai.gg)，选择喜欢的形象，确认名字，并选择朋友、恋人或前辈关系；选择恋人需确认已满 18 岁。
2. 点击「开始」，按提示登录或注册。已有账号使用原账号；登录后以账号保存的形象、名字和关系为准。
3. 新账号会先进入初遇序章，可以完成互动或跳过，然后开始自由聊天。
4. 在输入框写下想说的话并发送，例如：“今天有点累，陪我聊一会儿。”
5. 想听 Zai 的声音时，切换到语音回复；想实时交谈时，使用「语音通话」。两者的操作与用量见[聊天与语音](./chat-and-voice.md)。

完成初遇并选过回应后，满足回访条件时，之后一天回来可能会听到 Zai 回扣那句话；这不是定时推送通知。形象、名字、声音和关系之后都可以在设置中调整。

## 账号与使用权益 {#account-and-access}

遇见 Zai 使用 ZAI 平台账号。跨产品打开时可能需要重新登录，但不需要为每个产品创建一个账号。注册、密码找回和支持渠道见[账号、余额与支持](../platform/account.md)。

遇见 Zai 的免费版、Zai Plus 和语音等权益在产品的会员页面查看。API 与 ZaiDrama 使用的平台美元余额，不能等同于遇见 Zai 的会员权益或语音额度；详见[会员与用量](./plans-and-usage.md)。

## 几个入口里的 Zai {#which-zai}

- **zai.gg 的 Zai**：这里介绍的 AI 伙伴，提供日常陪伴、相处设置和记忆管理。
- **官网首页与开发者控制台的 Zai**：平台助手，帮助了解产品、查文档和 API 使用方式。
- **ZaiDrama 里的 Zai**：创作助手，和你一起推进创作项目或画布任务。

这些入口服务于不同用途。本文的操作步骤以 zai.gg 为准。
