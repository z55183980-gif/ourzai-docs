# 形象、声音与相处关系 {#appearance-and-relationship}

在遇见 Zai 的设置中，可以分别调整外观、声音和相处方式。

## 更换形象 {#appearance}

打开「设置 → 形象」，选择喜欢的形象。页面也提供自定义形象入口；涉及生成时，先查看页面显示的权益和剩余次数。

换形象会带来推荐音色；如果你已经手动选过音色，原先的选择会保留。更换形象不会改变名字、性格和记忆。

## 选择声音 {#voice}

打开「设置 → 声音」，选择音色并调整音量。这里也显示本期语音回复的剩余时长。

创建自己的音色是否可用，取决于当前语音模型的支持情况。页面提示暂不支持时，已有音色会保留；当前模型无法使用已选的自定义音色时，会暂用形象默认声音，恢复支持后再使用你的选择。

语音回复与实时通话的操作见[聊天与语音](./chat-and-voice.md)。

## 修改名字 {#name}

在「设置 → 相处关系」找到「TA 的名字」，点击修改并保存。名字只影响称呼，不会重置性格或记忆。

## 选择相处关系 {#relationship}

在「设置 → 相处关系」中选择：

| 关系 | 相处方式 |
| --- | --- |
| 朋友 | 平等、随意，可以开玩笑，也会直接表达看法 |
| 恋人 | 更亲昵地表达关心与想念 |
| 前辈 | 更注重督促、建议和直接指出问题 |

选择恋人关系时，页面会要求确认已年满 18 岁，确认后才保存。关系选择会影响互动方式，Zai 的身份仍然是 AI。

保存失败时按提示重试，并检查页面当前选中的关系。若想清理过往聊天或记忆，使用[记忆与数据管理](./memory-and-data.md)中的对应操作。
