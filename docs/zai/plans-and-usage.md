# 会员与用量 {#plans-and-usage}

遇见 Zai 提供免费版、Zai Plus 会员和加量包。登录后访问 [Zai Plus](https://zai.gg/subscription) 比较方案与购买；查看自己的剩余额度和恢复日期，请打开产品菜单中的「会员」。

## 查看计划与价格 {#plans}

页面显示免费版与 Zai Plus 的权益，以及不同相伴时长的价格。购买前核对所选时长、实际支付金额和所含额度；具体价格、额度与可用方案以该页面为准。

Zai Plus 采用一次性付款，到期不会自动续费。已有会员时，再购买的时长会接在现有有效期之后。支付完成后返回产品，确认会员状态和有效期已更新。

## 查看剩余用量 {#allowances}

在产品菜单打开「会员」，查看本期语音回复、语音通话剩余额度和恢复日期；「设置 → 声音」也能查看语音回复时长。独立的 `/subscription` 页面用于查看方案与购买，不显示本期用量。语音回复和通话分别计量，不能互相挪用。

定制形象的生成次数与语音分钟数分开计算；声音名额是可保存自定义音色的容量，不是每次使用声音都扣一次。具体数量以页面显示为准。

## 额度用完与加量包 {#extra-packs}

语音回复额度用完时，可以继续使用文字回复；语音通话额度用完时，页面会提示等待恢复或查看可用的加量包。

加量包仅限有效 Zai Plus 会员购买，采用一次性付款。

套餐随购买赠送的形象生成次数在会员有效期内可叠加，到期未用完的次数清零，已做好的形象保留。另购加量包可包括语音回复分钟、语音通话分钟、形象生成次数和音色名额：先用会员自带额度，再用对应加量包。加量包不按月重置；会员到期余额冻结并保留，重新开通后恢复，已保存的自定义音色不会因此删除。

## 与平台余额的区别 {#platform-balance}

API 调用与 ZaiDrama 媒体生成使用平台美元余额。遇见 Zai 的会员有效期、语音时长和加量包属于陪伴产品权益，应在会员中查看和购买。

给 API 或 ZaiDrama 充值，不等于购买 Zai Plus；平台余额也不代表剩余语音分钟数。平台充值记录与相关规则见[账号、余额与支持](../platform/account.md#credits)。

## 付款后权益没有更新 {#payment-help}

先确认登录的是购买时使用的账号，再刷新会员页面查看有效期与额度。付款仍在处理中时，等待付款结果；已成功付款但权益持续未更新时，联系 support@ourzai.com，提供注册邮箱、订单信息和发生时间。

申请退款及相关条款入口见[退款](../platform/account.md#refunds)。
