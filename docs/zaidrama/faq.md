# ZaiDrama 常见问题 {#faq}

本文汇总 ZaiDrama 创作应用中最常见的账号、制作、生产与下载问题。第一次使用时，建议先阅读[ZaiDrama 入门教程](./getting-started.md)；平台账号与余额见[账号、余额与支持](../platform/account.md)。

## 使用 ZaiDrama 前需要了解哪些能力边界？ {#capability-boundaries}

- 媒体生成由平台统一调度上游模型服务，生成速度、可用性和内容策略会随当前能力状态变化。
- Zai 会自动推进大部分步骤，但长篇内容仍建议你审阅方案、角色定妆图和关键片段；ZaiDrama 的目标是增强创作者，而不是取消判断。
- 不同视频模型对参考图数量、时长、音轨和分辨率的支持不同。
- 打开网站并登录即可开始，无需安装软件或配置第三方 API 密钥。

## 注册、登录与账户 {#install-deploy-update}

### 普通用户怎样开始？ {#how-to-install}

在落地页点「开始创作」，注册或登录统一平台账号后进入首页，在输入框里说出你想做的视频，或附上小说、剧本和参考图。发送第一句话就会建好项目并进入项目页，这一步不产生费用。

### 怎样登录？忘记密码怎么办？ {#default-login}

- 登录弹窗支持邮箱或用户名登录；没有默认账号，需要先注册。
- 忘记密码时在登录弹窗点「忘记密码？」，用邮箱验证码重置。
- 已登录时想换密码，在账户菜单的「个人中心」点「修改密码」。
- 从 ourzai.com 点「创作工作台」进入，已有有效登录状态时无需再次输入密码；ZaiDrama 与 ZAI 平台共用同一个账号。

不要要求任何人通过聊天发送你的密码或验证码。

### 怎样查看登录设备或注销账号？ {#account-security}

在「个人中心」的「登录设备」里可以看到所有已登录设备，并对单个设备点「退出」；「注销账号」也在个人中心。

### 平台页面打不开或请求失败怎么办？ {#page-request-failure}

先确认网络连接和登录状态，刷新页面重试。只有单个项目或生成失败时，先看对话或批次页里写明的失败原因。持续失败时，在账户菜单的「帮助与反馈」联系在线客服，说明发生时间和所在页面；需要时可以在「设置 → 诊断日志」下载诊断日志发给客服。不要上传环境文件或在聊天中粘贴密钥。

### 平台怎样更新？会丢失项目吗？ {#platform-updates}

网站会自动更新，用户无需安装更新包。更新期间已提交给模型服务的视频会接着等待结果，少数进行中的图片任务可能被标记为中断，需要重新生成那一项。已完成的产物不会被新版本静默覆盖。

### 项目存在哪里？怎样备份？ {#where-is-data}

项目、素材和生成结果保存在平台上。建议下载需要长期保留的内容。你可以随时下载成片、可编辑包和旁白音频留存，但平台不提供项目级 ZIP 导出，账户和余额等数据也不包含在任何下载内容中。

### 存储空间满了怎么办？ {#storage-full}

在账户菜单的「存储空间」查看容量上限和各项目的占用，用「清理历史」删除不再需要的历史版本（只删历史版本，当前使用的版本保留）。

## 与 Zai 对话 {#setup-and-assistant}

### 开始制作前需要配置哪些凭据？ {#required-credentials}

不需要。普通用户只需统一平台账号；Zai 的对话、文本 / 图像 / 视频 / 语音能力和任务资源都由平台提供。

### 怎样让 Zai 开始或继续制作？ {#start-or-resume-assistant}

在项目的 Zai 对话里直接说明目标，例如「开始制作」「接着拍剩下的」。Zai 会先看项目当前进度，从没完成的地方继续。它需要你决定时会在输入框上方弹出提问卡或确认卡。

### Zai 会不会不问我就花钱？ {#assistant-spending}

不会超出你批准的范围：

- 开拍前 Zai 会给出报价，你点「批准并开拍」后，这笔额度内的步骤自动执行，不再逐步打断；
- 超出开拍额度、返工额度不足时，会再次弹卡确认；
- 分析源文、整理方案、首次写剧本这类不产生费用的动作会直接做完再告诉你；
- 要覆盖你亲手改过的内容时，也会先征得你同意。

### 可以先只拍一部分吗？ {#partial-production}

可以。对 Zai 说「先拍第一集」或「只拍前两段」，报价和额度只算这些片段，之后的分镜和视频都守这个范围。拍完后再告诉 Zai 接着拍剩下的。

### 我在工作台上直接改了东西，Zai 知道吗？ {#workbench-edits}

知道。你在资产库新增条目，Zai 会先读再问你要怎么用；切换版本、重新合成等操作会在对话里留一行记录，Zai 下次开口前会看到。Zai 要覆盖你改过的内容时会先请你确认，卡上逐条列出「旧 → 新」。

### Zai 无法启动或请求超时怎么办？ {#assistant-startup-failure}

先刷新页面；Zai 的连接断开后会自动重连，正在进行的这一轮不会因此中断。仍然无法使用时，记下发生时间，通过「帮助与反馈」联系在线客服。

## 模型与供应商 {#providers-models-api}

### ZaiDrama 支持哪些模型？我能自己选吗？ {#supported-providers}

平台按用途（文生图、图生视频、参考生视频、旁白等）为每次调用挑选模型，可用范围以产品页面为准。你可以在「项目信息」的剧集参数（专业模式）、项目设置的旁白配音和创意画布的生成面板里，从平台开放的候选中选择；Zai 的对话模型不能选。详见[模型与能力](./models.md)。

### 能在 ZaiDrama 里使用自己的模型供应商吗？ {#custom-provider-setup}

不能。ZaiDrama 提供可直接使用的模型，不支持添加自己的模型供应商。

- 想在自己的程序里调用平台上的模型：到开发者控制台创建 API 密钥，base_url 填 `https://api.ourzai.com/v1`，见 [API 快速开始](../api/quickstart.md)。
- ZaiDrama「设置 → API 令牌」创建的是供外部工具访问 ZaiDrama 本身的令牌，和开发者控制台的 API 密钥不是一回事。

### 生成失败了怎么办？ {#auth-rate-limit-timeout}

先看失败原因：对话里的提交卡片和批次页都会写明哪几个没成、为什么。上游限流或暂时不可用时平台会自动重试；重试无效时只重拍受影响的片段，不要重复提交整批。提交后发生超时，上游任务可能已经创建，不要连续盲目重试，稍等后查看结果，仍有问题再联系客服。

## 项目流程与生产 {#project-workflow-and-tasks}

### 需要先选说书、剧集或广告模式吗？ {#choose-mode-and-route}

不需要。项目没有内容模式，也没有创建后锁定的生成路线。Zai 根据素材为每个片段决定类型（表演、旁白、展示等）和视频生成方式（分镜引导或参考引导），同一集里可以混用。详见[创作流程](./workflows.md)。

### 源文件支持哪些格式？ {#supported-source-formats}

- 文件：`.txt`、`.md`、`.docx`、`.epub`、`.pdf`，单个文件不超过 50MB，一次最多附 5 个；
- 图片：PNG、JPG、WebP，单张不超过 5MB，一次最多 5 张；
- 首页和项目里的 Zai 输入框都可以直接附文件和图片；项目的「文稿」页也可以「上传源文件」；
- 一次粘贴很长的文字会自动收成一张「粘贴的文本」卡片，发送后存成源文。

扫描版 PDF 没有可提取的文字，需要先做 OCR；旧式 `.doc` 请先转成 `.docx`。

### 生产进度在哪里看？ {#production-progress}

- 顶栏中间的状态标签，例如「生产中 · 分镜 8/11」「需要你决定」；
- 工作台「看板」的五站进度、「需要你决定」和「最新产出」；
- 「批次」页逐批预览，每段可以查看发给视频模型的提示词和失败原因。

### 为什么生产停住了？ {#stage-blocked}

常见原因：

- 有一步在等你确认（看板会显示「有一步在等你确认」，确认卡在对话框上方）；
- 角色有多套造型，但某些片段还没选造型；
- 某一站有片段没做成，需要你决定重试还是修改；
- 这次开拍的范围已经做完，要接着拍剩下的需要告诉 Zai。

### 怎样暂停、继续或取消生产？ {#task-states}

直接在对话里告诉 Zai，例如「先暂停」「继续」「取消这次生产」。取消后再继续只会补做被取消或缺失的部分，已完成的结果会保留复用。

### 只想重拍某一段怎么办？ {#reshoot-segment}

在对话里说清哪一段、怎么改，例如「第 3 段她再冷一点」。Zai 会给出旧 → 新的改法对照，确认后只重做这一段视频。重拍使用开拍额度之外的返工额度，额度不够时会再请你确认。

### 怎样避免满意的版本被重新生成替换？ {#pin-version}

在该素材的「历史版本」里点「锁定当前版本」。锁定后重新生成的结果只进入历史候选，不会自动替换当前版本；也可以随时「切换到此版本」换回以前的结果。

## 画面、视频与声音 {#visuals-video-audio}

### 怎样提高角色一致性？ {#character-consistency}

先确认角色定妆图（一张图包含头肩特写和正面、侧面、背面全身），再生成分镜和视频。全局资产库支持搜索和跨项目复用。资产定义变化后，已有的分镜和视频不会被静默覆盖，而是标记为比当前内容旧，由你决定是否重拍。

### 角色在剧中换装怎么办？ {#character-looks}

为角色新增**造型**：在资产库的角色详情里点「新增造型」，填写发型、服装、配饰并生成定妆图（需要先有主造型定妆图）。然后在剧本里为每一段选择这个角色穿哪一套；没选的段会停在剧本步骤。也可以直接让 Zai 替你写造型、给片段补选造型。

### 怎样让相邻片段更连贯？ {#shot-continuity}

锁定角色、场景和造型后再生成视频，保持地点、时间、服装和出场角色描述一致。分镜引导的片段会参考前一段的分镜画面来衔接。

### 首帧和尾帧怎样使用？ {#first-and-last-frame}

项目里分镜引导的片段以分镜图作为视频首帧，不使用尾帧。需要同时控制首帧和尾帧时，可以在[创意画布](./canvas.md)的视频节点上打开「首尾帧」（取决于所选模型是否支持）。

### 为什么场景设计图里出现了人物？ {#people-in-scene-images}

场景设计图会要求不出现人物，但图片模型可能不完全遵循。可以重新生成场景图，或用图片编辑移除人物。

### ZaiDrama 支持配音吗？ {#voice-over-support}

- **对白**由视频模型直接生成人声。
- **旁白**的交付方式在「项目信息」的剧集参数里选择：后期配音（默认，成片不含旁白人声）或 TTS 配音（平台合成旁白）；配音模型、音色和语速在项目设置的「旁白配音」里调整。
- 旁白片段的播放器可以在「原音成片」和「TTS 叠加」之间切换。

### 能调整字幕样式吗？ {#subtitle-style}

可以。在「项目信息 → 字幕样式」里调整字号、垂直位置、颜色和字体，预览所见即烧进成片的样子，从下一次合成起生效。

## 创意画布 {#creative-canvas}

### 创意画布是什么？和项目有什么区别？ {#canvas-vs-project}

创意画布是属于你个人的自由画布，用节点摆放文本、图片、视频和音频，并直接在节点上生成。它不挂在项目下，没有剧本、批次和成片交付；想完整拍一部多集短剧用项目，想自由试验画面或做几段独立视频用画布。两者通过全局资产库共享素材。详见[创意画布](./canvas.md)。

### 画布里的 Zai 会直接花钱吗？ {#canvas-approval}

默认不会：Zai 每次要花钱生成时先弹出审批条，写明预计费用（美元）和余额，由你确认。你可以把审批方式改为「直接生成」，或在审批条上勾选「本轮后续自动确认」，让本轮剩下的生成在累计 $0.20 的上限内不再逐张确认。删除节点、清空画布这类不可撤回的操作始终需要确认。

### 画布能分享或备份吗？ {#canvas-share-export}

- 「分享」可以生成只读链接，对方无需登录即可查看，你可以随时撤销；
- 画布可以导出为 zip，也可以从 zip 导入；
- 「历史版本」可以预览、命名、恢复快照，或另存为新画布。

## 费用、数据与下载 {#cost-data-export}

### 在哪里查看余额和费用？ {#view-and-control-cost}

顶栏的余额徽章显示当前美元余额，点击可以查看使用明细；账户菜单的「账单与余额」有可用余额、冻结中的金额、余额明细和购买记录，也可以在那里充值。余额显示 2 位小数（向下截断），每笔扣费等明细显示 4 位小数。每日登录奖励和推荐奖励在「福利中心」。

### 能下载哪些内容？ {#project-zip-vs-full-backup}

- **成片视频**：批次页「审改」视图的「本集成片」→「下载」；
- **可编辑包**：视频片段播放器的「下载可编辑包」，一个 zip，内含视频、旁白音频、字幕（`.vtt` / `.srt`）和描述文件，便于在其他剪辑软件里继续加工；
- **旁白音频**：旁白的历史版本里「下载音频」。

平台不提供整个项目的 ZIP 导出。

### 可编辑包为什么缺少片段？ {#project-export-missing-clips}

可编辑包只包含已经成功生成的内容。缺少的片段请先在批次页查看失败原因，重拍或补生成后再重新下载。

### 有手机 App 吗？ {#mobile-app-support}

ZaiDrama 是 Web 应用，目前没有独立的 iOS 或 Android 原生 App。手机可以通过浏览器访问，但审阅批次、编辑画布更适合在桌面端进行。

### 可以商用或二次开发吗？ {#commercial-use}

ZaiDrama 的源码按 AGPL-3.0 发布，源码仓库见 [GitHub](https://github.com/z55183980-gif/zaidrama)。

## 效果与成本最佳实践 {#quality-and-cost-best-practices}

1. 先拍少量片段，验证画风、角色和节奏，再扩大范围。
2. 先确定角色定妆图和造型，再批量出分镜和视频。
3. 让相邻片段保持地点、时间、服装和角色描述一致。
4. 只让当前片段引用真正需要的资产，避免参考图过多稀释约束。
5. 单个片段有问题只重拍这一段；满意的版本及时锁定。
6. 以「账单与余额」的余额和明细规划生产范围。
