# ZaiDrama 入门教程 {#getting-started}

本教程带你在 ZaiDrama（AI 短剧创作应用，<https://zaidrama.com>）里完成第一部短剧：从一句话或一份剧本开始，和 Zai 把需求磨成方案，确认开拍报价，再到拿到可下载的成片。打开网站并登录即可开始，无需安装软件或准备第三方 API 密钥。

## 你将完成什么 {#what-you-will-build}

完成教程后，你将能够：

1. 注册并登录统一平台账号；
2. 在首页用一句话、一段小说或剧本、参考图启动项目；
3. 和 Zai 在同一条对话里形成创作简报、世界模型与制作蓝图；
4. 确认开拍报价，让 Zai 按批次推进分镜、视频和成片；
5. 在看板和批次页跟踪进度，对不满意的片段局部重拍；
6. 预览并下载成片与可编辑包。

## 预计时间与费用 {#time-and-cost}

- 发送第一句话、建立项目和讨论方案不产生费用；图片、视频和音频生成才从余额扣费（美元）。
- 视频生成耗时取决于片段数量、平台队列和所用模型。
- 余额、冻结中的金额和扣费明细在账户菜单的「账单与余额」查看；开拍前确认卡会写明这次要花多少。
- 建议第一次只用少量内容，或对 Zai 说「先拍前两段」，验证风格和效果后再扩大范围。

## 1. 注册并登录 {#create-account}

### 1.1 注册或登录 {#sign-in}

在落地页点「开始创作」或「登录 / 注册」：

- **登录**：在登录弹窗输入邮箱或用户名和密码。
- **注册**：在「创建你的 ZAI 账号」页面用邮箱验证码注册；密码至少 6 位，需同时包含字母和数字。
- **忘记密码**：在登录弹窗点「忘记密码？」，用邮箱验证码重置。
- **从 ZAI 平台进入**：在 ourzai.com 点「创作工作台」进入；已有有效登录状态时无需再次输入密码。

ZaiDrama 与 ZAI 平台共用同一个账号，在官网或开发者控制台注册的账号可以直接登录。登录状态过期或需要安全验证时，按页面提示重新登录。账号与余额的完整说明见[账号、余额与支持](../platform/account.md)。

### 1.2 账户菜单 {#account-services}

侧栏左下角的账户菜单提供：

| 入口 | 用途 |
| --- | --- |
| 个人中心 | 头像、昵称、邮箱绑定、修改密码、登录设备、注销账号 |
| 福利中心 | 每日登录奖励、推荐奖励 |
| 账单与余额 | 可用余额、余额明细、购买记录、充值 |
| 存储空间 | 已用容量、各项目占用、清理历史版本 |
| 帮助与反馈 | 在线客服 |
| 设置 | 外观与语言、API 令牌（供外部工具访问 ZaiDrama，与开发者控制台的 API 密钥不同）、关于、诊断日志 |

顶栏的余额徽章会显示当前美元余额，点击可查看使用明细。

## 2. 从首页启动项目 {#start-conversation}

### 2.1 说出你想做的 {#creative-intent}

首页标题是「今天想把什么做成视频？」。在输入框里写下任意一种起点：

- 一个故事点子或一句创作目标；
- 一段小说、剧本、大纲或产品介绍；
- 你对画风、时长、比例、受众的要求。

输入框下方的快捷入口可以帮你开头：「上传小说 / 剧本」直接打开文件选择；「我有一个点子」「写一集爽剧开篇」「给产品拍条广告」只把一句开头填进输入框，不会替你发送。

### 2.2 附上素材 {#source-intake}

用输入框的回形针按钮、拖拽或粘贴添加附件：

- **图片**：PNG、JPG、WebP，单张不超过 5MB，一次最多 5 张。图片会发给 Zai 看，适合做角色、场景或商品参考。
- **小说 / 剧本文件**：`.txt`、`.md`、`.docx`、`.epub`、`.pdf`，单个文件不超过 50MB，一次最多 5 个，发送后存成项目的源文。
- **长段粘贴**：一次粘贴较长的文字（约 800 字或 16 行以上）会自动收成一张「粘贴的文本」卡片，发送后同样存成源文，并占用一个文件名额；不想这样可以点「转回正文编辑」。

输入框单条消息上限 2 万字，更长的内容请作为文件附上。扫描版 PDF 没有可提取的文字，需要先做 OCR；旧式 `.doc` 请先转成 `.docx`。

### 2.3 发送即建项目 {#create-project}

发送第一句话时，ZaiDrama 会建好项目并进入项目页，这句话和附件会在项目里的 Zai 对话中继续。首页不另存聊天记录，一个项目只有一条 Zai 对话，从讨论方案一直延续到成片。项目标题先显示为「未命名项目」，Zai 读完源文后会替它起名。

## 3. 认识项目页 {#project-workspace}

项目页分为三块：

- **主区：Zai 对话**。你在这里提需求、回答提问、确认报价，Zai 在这里汇报每一步做了什么。
- **右侧：工作台**。可拖宽、可收起。「看板」常驻最左；点「+」可以打开「批次」「文稿」「资产库」「项目信息」，项目有商品时还会出现「产品」。每个页面是一个可关闭的标签。
- **左侧：制作进度大纲**。按「前期准备 / 剧本制作 / 资产准备 / 逐集制作 / 成片交付」显示当前进行到哪一步。

刚进项目时，工作台会自动翻到 Zai 当前这一步对应的页面；之后你切到哪一页由你决定。顶栏中间的状态标签（如「生产中 · 分镜 8/11」「需要你决定」）点一下就能回到看板。

## 4. 和 Zai 确定方案 {#confirm-project}

### 4.1 剧本体检与提问 {#script-review}

如果你给了小说或剧本，Zai 会先读完并做一次剧本体检：挑出缺集、逻辑漏洞、闲置角色、没有铺垫的转折等问题（最多 5 条，每条附原文和改法），再问你要不要改。

Zai 需要你拍板时会弹出提问卡，停在输入框上方：选项可能标有「推荐」，可以用数字键直接选，按 Esc 跳过；选项都不合适就直接在输入框里写，也算回答（一次问好几个时，卡上另有「其他…」给某一问单独写）。选「我有剧本 / 小说」这类选项会把你带到输入框，贴正文或点 + 上传文件即可。

### 4.2 三层方案 {#choose-content-mode}

Zai 把需求整理成三层可修改的方案：

- **创作简报**：要做什么、给谁看、在哪发、多长、什么语气；
- **世界模型**：角色（身份与造型）、场景、道具、商品、视觉风格与连续性规则；
- **制作蓝图**：把作品拆成若干片段，每段写明类型、时长、出场人物和视觉/声音方向。

项目不需要先选「短剧 / 说书 / 广告」这类模式，也不需要先选「分镜 / 参考图」路线：每个片段各自决定怎么生产，同一部作品可以混用。导入小说或剧本后，Zai 还会推荐项目风格（仿真人、3D 漫剧或 2D 漫剧），默认仿真人。

整理方案、分析源文、首次写剧本这类不花钱的动作，Zai 会直接做完再告诉你。只有它要覆盖你亲手改过的内容时，才会弹卡请你确认。详见[创作流程](./workflows.md)。

### 4.3 采纳方案与开拍确认 {#proposal-gate}

方案成形后，对话框上方会出现确认横幅：

- **采纳制作方案**：剧本或资产图还没就绪时，先采纳方案，本步不产生费用。
- **开拍确认**：卡片标题写明「开拍要花 $N」（美元），点「看明细」可以看到片段数、视频秒数、分镜数、设定图数，以及余额变化和未包含的项目（例如返工）。点「批准并开拍」后，这笔额度记在当前项目上，额度内的步骤会自动执行，不再逐步打断你。

开拍可以只拍一部分：对 Zai 说「先拍第一集」或「只拍前两段」，报价和额度只算这些片段，之后的分镜和视频都守这个范围。

确认卡摆着时，你在输入框里说一句新的话，这张卡就会作废，Zai 按你的新要求重来。

## 5. 审阅文稿与资产 {#review-script-assets}

### 5.1 文稿 {#script-documents}

工作台的「文稿」页列出「原始文稿」和按「第 N 批」分组的剧本，每批包含「批次原文」和「正式剧本」。点「上传源文件」可以继续补充素材。

打开正式剧本可以看到每个片段的内容。角色有多套造型时，每一段都要在「造型」下拉里选一套，没选的段会显示「未选择」，出分镜前必须补上。

剧本由 Zai 直接写好，写完你可以随时查看和修改；你改过的内容，Zai 之后要覆盖时会先征得你同意。

### 5.2 角色、场景和道具 {#asset-review}

「资产库」页按角色、场景、道具分组，可以筛选、新增，或「从资产库选择」复用跨项目的资产：

- **定妆图**：每个角色一张，包含头肩特写和正面、侧面、背面全身，是后续出图的身份锚点。
- **造型**：一个角色可以有多套造型（发型、上装、下装、鞋、配饰）。主造型之外的变体以主造型定妆图为身份参考，因此要先生成主造型定妆图。
- **声音**：可以为角色设置参考音频，或用 TTS 生成一段。
- **历史版本**：资产图、分镜、视频都能「切换到此版本」；「锁定当前版本」后，重新生成的结果只进入历史候选，不会替换当前版本。

你在资产库新增的条目会自动告诉 Zai。资产定义变化后，已经生成的分镜和视频不会被静默覆盖，而是标记为「比当前内容旧」，是否重做由你决定。

## 6. 跟踪生产 {#run-production}

### 6.1 看板与状态 {#production-gates}

开拍后，「看板」变为生产看板：

- **各站进度**：方案与剧本、设定图、分镜、视频、成片五站；
- **需要你决定**：例如某一步超出额度在等确认，或某一站有几个没做成；
- **最新产出**：刚生成的内容带「新」标记。

对话里的每一步会以提交卡片显示结果，例如「生成视频 · 已完成」「动用开拍额度」「用时 …」；部分失败时会写明「N 个里 M 个没成，其余已经做好」。

### 6.2 批次页 {#task-status}

生产以批次为单位推进：一批的分镜和视频都做完，就进入下一批。「批次」页的标题栏可以切换上一批 / 下一批，并有两种视图：

- **预览**（默认）：连播这一批，镜头脚本随播放逐行滚动；每段可以查看发给视频模型的提示词，下方有画面轨与音频轨。没跑成的段会写明原因，并提供「再试一次」。
- **审改**：本集成片、制作状态、本批角色、分镜图、候选审片和视频片段。

想暂停、继续或取消生产，直接在对话里告诉 Zai。任务状态包括排队中、生成中、已完成、已失败、已取消和已中断；平台重启时，已提交给模型服务的视频会接着等结果，少量进行中的图片任务可能标记为中断，需要重新生成对应的那一项。

### 6.3 局部重拍 {#rerun-and-versions}

对某一段不满意时，在对话里说清哪段、怎么改（例如「第 3 段她再冷一点」）。Zai 会给出旧 → 新的改法对照，确认后只重做这一段视频。

- 重拍和自动返修从单独的返工额度出，不占用开拍额度；返工额度不够时会再弹卡确认。
- 自动校验判定失败的产物会被自动返修，同一问题返修到上限后交回你决定。
- 「候选审片」按评分列出候选版本，可以「选定并锁定」「退回」「再出一条」或「按建议返修」。

你在工作台上直接做的改动（例如切换版本、重新合成）会在对话里留一行记录，Zai 下次开口前会知道。

## 7. 预览与下载 {#preview-and-export}

批次页「审改」视图顶部的「本集成片」提供：

- 预览成片并开关「成片字幕」；
- 「下载」成片视频；
- 「历史版本」查看以前的成片，标「当前」的是正在使用的版本；
- 「重新合成」。

视频片段的播放器提供：

- 旁白片段可切换「原音成片」与「TTS 叠加」；
- 「下载可编辑包」：一个 zip，内含视频、旁白音频、字幕（`.vtt` / `.srt`）和描述文件，便于在其他剪辑软件里继续加工。

字幕的字号、位置、颜色和字体在「项目信息 → 字幕样式」里调整，从下一次合成起生效。

建议下载需要长期保留的成片和素材。

## 8. 模型与参数 {#provider-boundary}

「项目信息」页的「剧集参数」有两种模式：

- **自动模式**：只选「视频质量」（快速 / 标准 / 高质量）和画面比例（竖屏 9:16 / 横屏 16:9），模型由平台决定。
- **专业模式**：按用途（图生视频、参考生视频、文生图、图生图）选择模型和分辨率，默认「跟随全局路由」；还可以设置是否生成音频和项目风格。

两种模式都可以设置旁白交付方式（后期配音或 TTS 配音）和字幕样式。项目菜单的「项目设置…」可以改项目风格和旁白配音模型、音色、语速。Zai 使用的对话模型由平台配置，用户不能选择。

可选的模型只来自平台当前开放的候选。能力不可用、任务失败或扣费异常时，先看对话里的失败原因；仍无法解决时通过「帮助与反馈」联系在线客服。不要在对话里粘贴任何 API Key 或密码。
