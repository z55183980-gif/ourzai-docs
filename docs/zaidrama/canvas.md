# 创意画布 {#canvas}

创意画布是一块自由摆放灵感、参考和生成结果的无限画布。你可以在节点上直接生成图片、视频、文本和语音，把一张图接到下一个节点继续加工，也可以让画布里的 Zai 帮你改图、出视频。它适合试风格、做概念图、打磨单个镜头，或者做一条不需要完整剧本的短视频。

## 1. 画布和项目的关系 {#canvas-and-projects}

- 画布属于你个人，不挂在任何项目下；项目也不会读取画布内容。
- 画布不是第二条生产管线：它没有剧本、批次和成片交付，生成结果不会自动进入项目。
- 两者通过**全局资产库**互通：画布里的图片可以「存入资产库」，项目在资产库页用「从资产库选择」复用；画布侧栏的「资产」标签也能把资产库里的内容放到画布上。

需要把一个故事完整拍成多集短剧时，用项目；想先自由试验画面、或只做几段独立视频时，用画布。

## 2. 创建与管理画布 {#manage-canvases}

在侧栏点「创意画布」进入画布列表。第一次进来、还没有任何画布时，会直接打开一张空白画布。

列表按「今天 / 最近 7 天 / 更早」分组，卡片写明画布上有什么。在列表里可以：

- 在顶栏搜索画布名称或内容；
- 「新建画布」，或从已有画布「复制」一份；
- 「导入」一个画布 zip，或把画布「导出」为 zip（导入时认不出的包只会导入其中的媒体）；
- 「选择」多张画布批量导出或删除；
- 重命名、删除画布。

画布会按内容自动起名：第一次放进有文字的内容时按第一个节点起名，Zai 在画布上做过东西后按这一轮的需求起名；你改过的名字不会被覆盖。新建后什么都没做就关掉的空白画布会被自动丢弃，不会留在列表里。

每张画布在新的浏览器标签页中打开。画布会自动保存，顶栏显示「已保存 / 保存中… / 未保存」；同一张画布在两个窗口里同时编辑发生冲突时，会提示「与另一窗口的改动冲突」。

## 3. 节点与连线 {#nodes}

工具栏提供：

- **选择 / 抓手**：选中节点或拖动画布；
- **添加节点**：文本、图片、视频、音频；多个节点可以放进一个分组；
- **上传文件**：PNG、JPG、WEBP、MP4、WEBM、MP3、WAV，图片不超过 20MB，视频不超过 200MB，音频不超过 30MB；
- **使用已有素材**：从你上传或生成过的素材中挑选；
- **预设**：例如「脚本生成器」「角色三视图」，一次摆好一组常用节点；
- **画布设定**：默认画幅、默认清晰度、背景样式，以及「清空画布」。

节点之间的连线表示输入关系：把图片节点连到视频节点，它就成为视频的首帧或参考。

侧栏有「画布」「资产」「提示词」三个标签。「提示词」里有公共合集和「我的」提示词库。

## 4. 在节点上生成 {#generate}

选中节点即可打开生成面板：

| 生成 | 可设置 |
| --- | --- |
| 生成图片 | 生成模型、清晰度、生成数量、画面比例、风格；比例选「智能」时按第一张参考图取最接近的比例 |
| 生成视频 | 连一张图作首帧（成片通常跟随首帧的比例）；连两张及以上的图时全部作为参考图，用 `@` 指明谁是谁，成片按所选比例出；打开「首尾帧」时前两张作首帧和尾帧；分辨率、时长、是否「生成音频」 |
| 生成文本 | 写作要求 |
| 语音合成 | 音色、语速 |

生成完成后，节点上的快捷操作可以接着「生成视频」「生成图片」「配旁白」「续写下一镜」。

图片节点还提供反推提示词、裁剪、切图、放大、局部编辑、多角度、截取视频的首帧 / 当前帧 / 尾帧、存入资产库等工具。其中裁剪、切图和放大在浏览器里完成，不产生费用。

可选的生成模型来自平台为对应用途开放的候选，见[模型与能力](./models.md)。

## 5. 画布里的 Zai {#canvas-zai}

画布右下角的 Zai 窗口可以拖动和缩放，双击回到右下角。它看得见这张画布，也能替你改：

- **作用范围**：选中节点时只处理「已选 N 个节点」，否则处理「整张画布」；
- **看素材**：能查看节点里的图片、视频和音频；
- **联网检索**：需要时会检索网络资料，检索回来的内容只作参考材料；
- **备忘录**：面板顶部的备忘录每一轮 Zai 都会读到，你和 Zai 都可以编辑；画幅、风格、清晰度等画布默认设置会自动带到新画布，不需要写进备忘录；
- **撤销这一轮**：一键撤回 Zai 这一轮对画布的全部修改。

画布 Zai 不预设你在拍短剧，写故事、做海报、做产品图都可以。它使用的对话模型由平台配置。

### 5.1 生成前确认 {#approval}

Zai 要花钱生成时，默认先弹出审批条，写明预计费用（美元）和余额，你点「确认生成」后才执行；点「在画布上查看」可以先看它要改哪些节点。

- 在 Zai 面板的审批方式里可以改为「直接生成」，之后 Zai 不再逐次请示。
- 审批条上勾选「本轮后续自动确认」，本轮剩下的生成在累计 $0.20 的上限内不再逐张弹卡，超出上限的那一次照常确认。
- 删除节点、清空画布等不可撤回的操作始终需要确认。

## 6. 历史版本 {#history}

顶栏的「历史版本」可以预览、命名或恢复画布快照：

- 编辑时平台会定期自动留存版本；删除内容、恢复版本和 Zai 修改画布之前也会各留一份；
- 「存为版本」并命名的版本不会被自动清理；
- 可以「恢复此版本」，也可以「另存为新画布」。

## 7. 分享 {#share}

顶栏的「分享」可以生成**只读链接**：拿到链接的人无需登录即可查看这张画布，但不能编辑。你随时可以「撤销链接」，撤销后链接立即失效。
