# ZaiDrama 的模型与能力 {#providers}

本页说明在 ZaiDrama 中如何选择模型、了解能力与处理生成问题。想在自己的程序里直接调用平台上的模型，见 [API 快速开始](../api/quickstart.md)。

在 ZaiDrama 里创作无需准备第三方 API 密钥。ZaiDrama 按**用途**为每一次调用挑选模型，你只在少数地方从平台开放的候选中做选择。

## 1. 按用途选模型 {#model-usages}

每一次模型调用都属于一个固定用途：

| 类别 | 用途 | 用来做什么 |
| --- | --- | --- |
| 文本 | 简单任务 | 源文概述、风格图分析、一致性检查 |
| 文本 | 复杂任务 | 剧本、批次规划、画布写作 |
| 文本 | 画布助手 | 创意画布里替你动手的 Zai |
| 文本 | 画布看图听声 | 画布 Zai 查看节点里的图片、视频、音频 |
| 文本 | 联网检索 | 画布 Zai 需要实时信息时联网查询 |
| 图片 | 文生图 | 角色图、场景图、分镜图等纯文字出图 |
| 图片 | 图生图 | 带参考图的出图与图片编辑 |
| 视频 | 图生视频 | 分镜首帧驱动的视频与宫格 |
| 视频 | 参考生视频 | 用角色、场景、道具或产品参考图直接生成视频 |
| 音频 | 旁白 | 旁白配音与角色声音试听 |

使用默认选择时，平台会为对应用途选择当前可用的模型。

## 2. 你能在哪里选模型 {#user-model-selection}

| 位置 | 能选什么 |
| --- | --- |
| 项目信息 → 剧集参数 → 自动模式 | 不选模型，只选「视频质量」（快速 / 标准 / 高质量）和画面比例，平台按质量档挑选模型 |
| 项目信息 → 剧集参数 → 专业模式 | 为图生视频、参考生视频、文生图、图生图分别选模型和分辨率；默认「跟随全局路由」 |
| 项目设置 → 旁白配音 | 默认旁白配音模型、旁白音色和语速 |
| 创意画布 → 节点生成面板 | 这一次生成使用的模型 |

- 下拉菜单显示该用途当前可选的模型。
- 项目里指定的模型暂时不可用时，界面会提示「项目指定的模型此刻不可用」，可以改回「跟随全局路由」。
- Zai 的对话模型和其他文本用途由平台配置，用户不能选择。
- 个人「设置」页没有模型选项。

首次制作建议先用少量片段验证风格和效果，再扩大范围。

## 3. 能力边界 {#capability-boundaries}

平台按具体模型声明能力，而不是按供应商整体推断。下面是能力类别，某个模型具体支持哪些，以生成面板和下拉里实际可选的项为准：

- **文本**：结构化输出、看图（图像输入）；
- **图像**：文生图、图生图（带参考图出图与编辑），支持的分辨率与比例；
- **视频**：图生视频（首帧驱动，部分模型支持尾帧）、参考生视频（多参考图，数量和类型因模型而异）、参考音频、支持的时长、分辨率和比例；
- **视频音轨**：有的模型可以选择是否生成音轨，有的总是带声音，有的总是无声；
- **语音**：TTS 与可选音色；语速在项目设置或画布语音节点里调整。

请求超出模型声明的能力（例如给不支持尾帧的模型传尾帧）会在提交前被明确拒绝，不会静默换成你没选的模型。

## 4. 费用与额度 {#credits-and-usage}

用户以账户菜单「账单与余额」中的可用余额和余额明细为准。平台会记录每次生成的用途、模型、状态和费用（美元）；每次生成按「费率 × 用量」扣费，精确到 $0.0001，最低 $0.0001。扣费结果以余额明细为准。

遇到余额不足或扣费异常时，记下项目名称和发生时间，通过「帮助与反馈」联系在线客服，不要重复点击生成或尝试绕过额度检查。

## 5. 故障排查 {#troubleshooting}

### 用户侧 {#user-troubleshooting}

- **下拉里没有某个模型**：该用途未提供这个模型，或模型暂时不可用；
- **项目指定的模型不可用**：改回「跟随全局路由」，或换一个候选；
- **生成失败**：先看对话或批次页里写明的失败原因，只重拍受影响的片段；
- **排队过久**：任务由平台统一调度，请勿重复提交；
- **余额不足**：到「账单与余额」查看余额和明细。
